# ما هو JSON؟

---

## 📝 مقدمة

في هذا الدرس تم شرح:

- مفهوم **JSON (JavaScript Object Notation)**.
- العلاقة بين JSON و XML.
- لماذا يعتبر JSON أخف من XML.
- استخدام JSON في تخزين البيانات وتبادلها.
- مقارنة بسيطة بين JSON و XML.

---

## 🎯 ما هو JSON؟

**JSON** اختصار لـ:

> **JavaScript Object Notation**

وهو تنسيق (Format) يستخدم لتمثيل البيانات بشكل نصي منظم.

يستخدم بشكل أساسي من أجل:

- تخزين البيانات.
- تبادل البيانات بين التطبيقات.
- التكامل بين الأنظمة (Integration).

---

## 🔄 العلاقة بين JSON و XML

كل من JSON و XML يهدفان إلى:

- تمثيل البيانات.
- تخزين البيانات.
- نقل البيانات بين الأنظمة.

ويعتمدان على النصوص (Plain Text)، لذلك يمكن استخدامهما على جميع أنظمة التشغيل.

---

## ⚡ لماذا يعتبر JSON أخف من XML؟

في XML يوجد Tag بداية وTag نهاية لكل عنصر، مثل:

```xml
<Name>Ali</Name>
```

أما في JSON فلا توجد Tags افتتاحية وإغلاقية، مما يقلل عدد الأحرف ويجعل حجم الملف أصغر.

ولهذا يعتبر JSON:

- أخف حجماً.
- أسرع في النقل.
- أكثر استخداماً في كثير من عمليات التكامل الحديثة.

---

## 👥 قابل للقراءة من الإنسان والآلة

تم تصميم JSON بحيث يكون:

- **Human Readable**
- **Machine Readable**

أي يمكن للإنسان فهمه بسهولة، كما تستطيع البرامج قراءته وتحليله بسهولة.

---

## 🌍 مستقل عن نظام التشغيل

بما أن JSON عبارة عن نص (Plain Text)، فيمكن استخدامه على:

- Windows
- Linux
- macOS
- Android
- iOS

ولذلك فهو يعتبر:

> **Platform Independent**

---

## 🔄 تبادل البيانات بين الأنظمة

يستخدم JSON لنقل البيانات بين:

- تطبيق وآخر.
- جهاز وآخر.
- أنظمة تشغيل مختلفة.

مثال:

- تطبيق يعمل على Windows.
- تطبيق آخر يعمل على Linux.

يمكنهما تبادل البيانات باستخدام JSON.

---

## ⚙️ استخدامات JSON

يمكن استخدام JSON في:

- تخزين البيانات.
- تبادل البيانات بين التطبيقات.
- عمليات التكامل (Integration).
- ملفات الإعدادات (Configuration Files).

مثل:

- إعدادات قاعدة البيانات.
- لغة التطبيق.
- ألوان واجهة المستخدم.
- إعدادات البرنامج المختلفة.

---

## 📚 دعم لغات البرمجة

JSON ليس مرتبطاً بلغة JavaScript فقط.

رغم أن اسمه يحتوي على JavaScript، إلا أن جميع لغات البرمجة تقريباً تدعم JSON من خلال مكتبات جاهزة.

مثل:

- C#
- Java
- C++
- Python
- JavaScript
- Visual Basic .NET

---

## 🛠️ التعامل مع JSON

توفر معظم لغات البرمجة مكتبات تساعد على:

- قراءة JSON.
- تحليل البيانات (Parsing).
- استخراج البيانات.
- البحث داخل البيانات.
- التعديل عليها.

---

## 📊 مقارنة بين XML و JSON

| XML | JSON |
|------|-------|
| يستخدم Tags للبداية والنهاية | لا يستخدم Tags مغلقة |
| أكبر حجماً | أخف حجماً |
| مناسب لتبادل البيانات | مناسب لتبادل البيانات |
| واسع الاستخدام | واسع الاستخدام |
| قابل للقراءة من الإنسان والآلة | قابل للقراءة من الإنسان والآلة |

---

## 💡 لماذا يفضل كثير من المطورين JSON؟

يفضل الكثير من المطورين JSON لأنه:

- أقل حجماً.
- أسرع في الإرسال والاستقبال.
- أسهل في القراءة والكتابة.
- يؤدي نفس الغرض الذي تؤديه XML في كثير من الحالات.

ومع ذلك، ما زالت XML مستخدمة بشكل واسع في العديد من الأنظمة.

---

## 🔑 الخلاصة

- **JSON** اختصار لـ **JavaScript Object Notation**.
- يستخدم لتخزين البيانات وتبادلها.
- يعتمد على النصوص (Plain Text).
- يمكن قراءته من الإنسان والآلة.
- يعمل على جميع أنظمة التشغيل.
- أخف حجماً من XML.
- يستخدم بشكل واسع في التكامل بين التطبيقات والأنظمة.
- لا يقتصر استخدامه على لغة JavaScript.

# What is JSON?

---

## 📝 Introduction

This lesson explains:

- The concept of **JSON (JavaScript Object Notation)**.
- The relationship between JSON and XML.
- Why JSON is lighter than XML.
- How JSON is used to store and exchange data.
- A comparison between JSON and XML.

---

## 🎯 What is JSON?

**JSON** stands for:

> **JavaScript Object Notation**

It is a text-based format used to represent structured data.

Its primary purposes are:

- Storing data.
- Exchanging data between applications.
- Supporting system integration.

---

## 🔄 JSON and XML

Both JSON and XML are designed to:

- Represent data.
- Store data.
- Exchange data between systems.

Both formats use plain text, making them portable across different operating systems.

---

## ⚡ Why Is JSON Lighter Than XML?

In XML, every element has both opening and closing tags, for example:

```xml
<Name>Ali</Name>
```

JSON does not use opening and closing tags in the same way, resulting in fewer characters and smaller file sizes.

Because of this, JSON is generally:

- Smaller.
- Faster to transfer.
- Widely preferred for modern integrations.

---

## 👥 Human and Machine Readable

JSON is designed to be:

- **Human Readable**
- **Machine Readable**

Both developers and software can easily understand and process it.

---

## 🌍 Platform Independent

Since JSON is plain text, it works on virtually every operating system, including:

- Windows
- Linux
- macOS
- Android
- iOS

Therefore, JSON is considered:

> **Platform Independent**

---

## 🔄 Data Exchange Between Systems

JSON is commonly used to exchange information between:

- Different applications.
- Different computers.
- Different operating systems.

For example:

- A Windows application.
- A Linux application.

Both can exchange data using JSON.

---

## ⚙️ Common Uses of JSON

JSON is commonly used for:

- Data storage.
- Data exchange.
- System integration.
- Configuration files.

Examples include:

- Database connection settings.
- Application language.
- UI themes.
- Application settings.

---

## 📚 Programming Language Support

Although its name includes JavaScript, JSON is not limited to JavaScript.

Almost every programming language provides libraries for working with JSON, including:

- C#
- Java
- C++
- Python
- JavaScript
- Visual Basic .NET

---

## 🛠️ Working with JSON

Programming libraries make it easy to:

- Read JSON.
- Parse JSON.
- Extract data.
- Search data.
- Modify data.

---

## 📊 XML vs JSON

| XML | JSON |
|------|-------|
| Uses opening and closing tags | Uses a lighter structure |
| Larger file size | Smaller file size |
| Used for data exchange | Used for data exchange |
| Widely supported | Widely supported |
| Human and machine readable | Human and machine readable |

---

## 💡 Why Do Many Developers Prefer JSON?

Many developers prefer JSON because it is:

- Smaller.
- Faster to transfer.
- Easier to read and write.
- Suitable for many of the same scenarios as XML.

XML, however, continues to be widely used in many existing systems.

---

## 🔑 Summary

- **JSON** stands for **JavaScript Object Notation**.
- It is used to store and exchange data.
- It is based on plain text.
- It is both human-readable and machine-readable.
- It works across all major operating systems.
- It is generally lighter than XML.
- It is widely used for application and system integration.
- It is supported by virtually every programming language.
