# ما هو السيرفر؟

---

## 📝 مقدمة

في هذا الدرس تم التعرف على:

- مفهوم **السيرفر (Server)**.
- الفرق بين **السيرفر** و **الكمبيوتر الشخصي (PC)**.
- أشهر أنواع السيرفرات.
- أشكال السيرفرات.
- الأماكن التي توضع فيها السيرفرات.

---

## 🎯 ما هو السيرفر؟

السيرفر هو:

- **نوع من أنواع أجهزة الكمبيوتر.**
- وظيفته الأساسية **تقديم الخدمات للأجهزة أو المستخدمين الآخرين.**
- لذلك يسمى **الخادم (Server)**.

يقوم السيرفر بـ:

- استقبال الطلبات.
- تخزين المعلومات.
- معالجة المعلومات.
- مشاركة المعلومات مع المستخدمين.

---

## 💡 هل السيرفر جهاز مختلف عن الكمبيوتر؟

السيرفر في الأصل:

- **كمبيوتر عادي.**
- يمكن أن يكون Laptop أو PC.
- لكن عندما يصبح مخصصًا لتقديم الخدمات للأجهزة الأخرى يسمى **Server**.

فعندما يضع شخص موقعه الإلكتروني على جهازه الشخصي ويجعله يخدم المستخدمين، فإن هذا الجهاز يصبح **Server** لأنه يستقبل طلبات المستخدمين (**Requests**) ويقدم لهم الخدمة.

---

## 🔄 كيف يعمل السيرفر؟

يقوم المستخدمون بإرسال:

- **Request**
- **Request**
- **Request**

إلى السيرفر.

ثم يقوم السيرفر بالاستجابة لهذه الطلبات وتقديم الخدمة المطلوبة.

---

## 🔍 الفرق بين Server و PC

تشبيه:

- 🚗 **PC** بسيارة صغيرة.
- 🚚 **Server** بشاحنة كبيرة.

وهذا يوضح أن السيرفر يمتلك قدرة أعلى بكثير من الكمبيوتر الشخصي.

---

## 📊 مقارنة بين Server و PC

| الخاصية | Server | PC |
|---------|---------|----|
| ⚙️ الأداء | أعلى بكثير | أقل |
| ✅ الاعتمادية | أعلى | أقل |
| ⏱️ وقت التشغيل | يمكن أن يعمل لسنوات طويلة دون إيقاف | ليس مصممًا لذلك |
| 💾 العتاد (Hardware) | مواصفات أعلى | مواصفات عادية |
| 🧠 المعالج (CPU) | أقوى وقد يحتوي على عدة معالجات | أقل |
| 🧩 الذاكرة (RAM) | أكبر | أقل |
| 💽 مساحة التخزين | أكبر | أقل |
| 🗄️ Cache Memory | أكبر | أقل |
| 💰 السعر | أعلى بكثير | أقل |

---

## 🔑 لماذا يكون السيرفر أغلى؟

لأن مواصفاته أعلى من الكمبيوتر الشخصي، مثل:

- معالجات أقوى.
- عدد أكبر من المعالجات.
- ذاكرة RAM أكبر.
- مساحة تخزين أكبر.
- Cache Memory أكبر.

لذلك تكون تكلفة تصميمه وشرائه أعلى.

---

## 📂 أنواع السيرفرات

يعتمد اسم السيرفر على **الخدمة التي يقدمها**.

### 🌐 Web Server

- يستضيف مواقع الويب أو تطبيقات الويب.

---

### 📧 Mail Server

- مسؤول عن إدارة البريد الإلكتروني والاتصالات الخاصة به.

---

### 📦 Application Server

- يستضيف التطبيقات.

---

### 🗄️ Database Server

- يستضيف محرك قواعد البيانات (Database Engine).

---

### 📁 File Server

- مخصص لتخزين الملفات وتنظيمها وإدارتها.

---

### 🖼️ Image Server

- مسؤول عن معالجة الصور.

---

### 📞 Voice Server

- مخصص لخدمات **Voice over IP (VoIP)**.

---

### 🎮 Game Server

- يقدم الخدمات الخاصة بالألعاب.

---

### 🖨️ Print / Fax Server

- مسؤول عن الطباعة أو إرسال واستقبال الفاكسات.

---

### 💡 ملاحظة

جميع هذه الأنواع هي:

- **أجهزة كمبيوتر عالية المواصفات.**
- ويختلف اسمها حسب الخدمة التي تقدمها.

---

## 🏗️ أشكال السيرفرات

هناك ثلاثة أشكال رئيسية.

### 1️⃣ Tower Server

- يشبه الكمبيوتر الشخصي.
- يعمل بشكل مستقل (**Stand Alone**).
- يمكن وضعه على المكتب أو الأرض.

---

### 2️⃣ Rack Server

- سيرفر رفيع.
- يتم تركيبه داخل **Rack** داخل خزائن السيرفرات.
- يمكن إدخاله وإخراجه بسهولة مثل الأدراج.

---

### 3️⃣ Blade Server

- سيرفر رفيع جدًا.
- يمكن تركيبه بشكل أفقي أو عمودي داخل الهيكل المخصص له.

---

## 🏢 غرف السيرفرات (Server Rooms)

توجد السيرفرات عادة داخل:

- **Server Rooms**
- **Data Centers**

وتحتوي على:

- خزائن (Cabinets).
- Racks يتم تركيب السيرفرات بداخلها.

---

## ❄️ متطلبات تشغيل السيرفرات

السيرفرات تحتاج إلى بيئة خاصة لأنها تعمل لفترات طويلة.

من أهم المتطلبات:

- تبريد قوي جدًا.
- تشغيل أجهزة التكييف على مدار 24 ساعة.
- المحافظة على درجة حرارة منخفضة.

---

## 📍 مراكز البيانات (Data Centers)

تتميز مراكز البيانات بأنها:

- تحتوي على عدد كبير من السيرفرات.
- تمتلك أنظمة تبريد قوية.
- تضم أنظمة حماية ومكافحة الحريق.
- تكلفتها مرتفعة بسبب متطلبات التشغيل.

بعض الشركات تضع مراكز البيانات في مناطق باردة لتقليل تكلفة التبريد.

---

## 🔑 الخلاصة

- **السيرفر هو جهاز كمبيوتر مخصص لتقديم الخدمات.**
- يمكن أن يكون أي جهاز كمبيوتر، لكن عادة تكون مواصفاته أعلى بكثير.
- تختلف أسماء السيرفرات حسب نوع الخدمة التي تقدمها.
- توجد للسيرفرات ثلاثة أشكال رئيسية:
  - Tower Server
  - Rack Server
  - Blade Server
- توضع السيرفرات داخل **Server Rooms** أو **Data Centers** التي توفر التبريد والحماية اللازمة.

# What is Server?

---

## 📝 Introduction

This lesson explains:

- The concept of a **Server**.
- The difference between a **Server** and a **PC**.
- Common server types.
- Server forms.
- Where servers are typically located.

---

## 🎯 What is a Server?

A **Server** is:

- A type of computer.
- Designed to provide services to other users or devices.
- Therefore, it is called a **Server (Host)**.

Its main tasks are:

- Receiving requests.
- Storing information.
- Processing information.
- Sharing information with users.

---

## 💡 Is a Server Different from a Computer?

A server is originally:

- A normal computer.
- It can even be a laptop or a desktop PC.

When it is dedicated to providing services to other devices, it becomes a **Server**.

For example, if a website is hosted on a laptop and users access that website, the laptop is acting as a **Server**.

---

## 🔄 How Does a Server Work?

Users send:

- **Request**
- **Request**
- **Request**

to the server.

The server processes these requests and returns the required service.

---

## 🔍 Server vs PC

- 🚗 A **PC** is like a small car.
- 🚚 A **Server** is like a large truck.

This illustrates that a server is much more powerful.

---

## 📊 Server vs PC Comparison

| Feature | Server | PC |
|---------|---------|----|
| ⚙️ Performance | Much Higher | Lower |
| ✅ Reliability | Higher | Lower |
| ⏱️ Running Time | Can operate continuously for many years | Not designed for continuous operation |
| 💾 Hardware | Higher specifications | Standard specifications |
| 🧠 CPU | More powerful, possibly multiple processors | Less powerful |
| 🧩 RAM | Larger | Smaller |
| 💽 Storage | Larger | Smaller |
| 🗄️ Cache Memory | Larger | Smaller |
| 💰 Cost | Much Higher | Lower |

---

## 🔑 Why is a Server More Expensive?

Because it includes:

- More powerful processors.
- More CPUs.
- More RAM.
- Larger storage capacity.
- Larger cache memory.

These higher specifications increase its overall cost.

---

## 📂 Types of Servers

A server is named according to the service it provides.

### 🌐 Web Server

Hosts websites or web applications.

---

### 📧 Mail Server

Handles email communication.

---

### 📦 Application Server

Hosts applications.

---

### 🗄️ Database Server

Hosts a database engine.

---

### 📁 File Server

Stores and manages files.

---

### 🖼️ Image Server

Processes images.

---

### 📞 Voice Server

Handles Voice over IP (VoIP) services.

---

### 🎮 Game Server

Provides services related to games.

---

### 🖨️ Print / Fax Server

Handles printing or fax services.

---

### 💡 Note

All of these are:

- High-performance computers.
- Named according to the service they provide.

---

## 🏗️ Server Forms

There are three common server forms.

### 1️⃣ Tower Server

- Similar to a desktop PC.
- Stand-alone.
- Can be placed on a desk or on the floor.

---

### 2️⃣ Rack Server

- Thin server.
- Mounted inside a rack cabinet.
- Slides in and out like a drawer.

---

### 3️⃣ Blade Server

- Very thin server.
- Can be installed horizontally or vertically.

---

## 🏢 Server Rooms

Servers are usually installed inside:

- **Server Rooms**
- **Data Centers**

These contain:

- Cabinets.
- Rack systems that hold multiple servers.

---

## ❄️ Server Requirements

Servers require a dedicated environment because they operate continuously.

Key requirements include:

- Powerful cooling systems.
- Air conditioning running 24/7.
- Constant low temperatures.

---

## 📍 Data Centers

A Data Center:

- Contains many servers.
- Has powerful cooling systems.
- Includes fire protection systems.
- Is expensive to build and maintain due to cooling requirements.

Some companies place data centers in cold regions to reduce cooling costs.

---

## 🔑 Summary

- A **Server** is a computer dedicated to providing services.
- It can be any computer, but typically has much higher specifications.
- Server names depend on the services they provide.
- The three main server forms are:
  - Tower Server
  - Rack Server
  - Blade Server
- Servers are usually installed in **Server Rooms** or **Data Centers**, where proper cooling and protection are provided.
