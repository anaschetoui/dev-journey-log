# ما هو Domain Name؟ ومن أين يمكن الحصول عليه؟

---

## 📝 مقدمة

في هذا الدرس تم شرح:

- مفهوم **Domain Name**.
- العلاقة بين اسم النطاق وعنوان **IP Address**.
- سبب استخدام أسماء النطاقات.
- كيفية شراء Domain Name.
- أشهر المواقع التي توفر خدمة تسجيل النطاقات.

---

## 🌐 مراجعة سريعة

تعرفنا سابقًا على:

- كل موقع ويب يعمل على خادم (**Server**) يمتلك **IP Address**.
- يستخدم المتصفح **URL** للوصول إلى مواقع الويب.
- يتم الوصول إلى الخادم عبر عنوان IP حتى وإن لم يكن المستخدم يكتبه مباشرة.

---

## 🎯 ما هو Domain Name؟

**Domain Name** هو:

> **اسم سهل التذكر يرتبط بعنوان IP موجود على الإنترنت.**

بدلاً من كتابة عنوان IP في كل مرة، يمكن كتابة اسم بسيط مثل:

```text
programmingadvices.com
```

---

## 💡 لماذا نستخدم Domain Names؟

عناوين IP عبارة عن أرقام يصعب حفظها.

مثال:

```text
104.19.238.117
```

بدلاً من تذكر هذا الرقم، يكفي كتابة:

```text
programmingadvices.com
```

ليتم الوصول إلى نفس الخادم.

---

## 📱 مثال بسيط

يشبه Domain Name أسماء جهات الاتصال في الهاتف.

بدلاً من حفظ رقم هاتف كل شخص، يتم حفظ اسمه فقط.

عند الضغط على الاسم، يستخدم الهاتف الرقم الحقيقي لإجراء الاتصال.

بنفس الفكرة:

- المستخدم يتذكر اسم الموقع.
- النظام يستخدم عنوان الـ IP الحقيقي للوصول إلى الخادم.

---

## 🔗 العلاقة بين Domain Name و IP Address

كل Domain Name يرتبط بعنوان IP معين.

مثلاً:

```text
facebook.com
```

يرتبط بعنوان IP الخاص بخوادم Facebook.

وكذلك:

```text
programmingadvices.com
```

يرتبط بعنوان IP الخاص بخادم الموقع.

---

## 🌍 امتدادات أسماء النطاقات

من أشهر الامتدادات:

- .com
- .net
- .org
- .info
- .business
- .me
- .gov
- .edu

ويعتبر:

```text
.com
```

أكثرها استخدامًا.

---

## 🔑 أسماء النطاقات فريدة

كل Domain Name يجب أن يكون **Unique**.

إذا كان الاسم محجوزًا مسبقًا، فلا يمكن تسجيله مرة أخرى.

على سبيل المثال:

```text
facebook.com
```

أو

```text
programmingadvices.com
```

لا يمكن تسجيلهما مرة أخرى لأنهما مستخدمان بالفعل.

---

## 🛒 كيف تحصل على Domain Name؟

الخطوات الأساسية:

1. اختيار اسم النطاق.
2. البحث عن توفره.
3. شراؤه إذا كان متاحًا.
4. ربطه بعنوان IP الخاص بالخادم.

---

## 💰 تكلفة Domain Name

عادةً تكون تكلفة تسجيل Domain Name حوالي:

- **10 إلى 11 دولارًا سنويًا**

وقد تختلف الأسعار حسب الامتداد والشركة.

---

## 🌐 مواقع شراء Domain Names

من أشهر المواقع:

- Namecheap
- GoDaddy
- Domain.com

وتسمح هذه المواقع بـ:

- البحث عن الأسماء.
- معرفة إذا كان الاسم محجوزًا.
- شراء النطاق إذا كان متاحًا.

---

## 📍 ماذا يحدث بعد شراء Domain؟

شراء Domain Name يعني حجز الاسم فقط.

بعد ذلك يتم ربطه بعنوان IP الخاص بالخادم حتى يتمكن المستخدمون من الوصول إلى الموقع باستخدام الاسم بدلاً من عنوان IP.

---

## 🖥️ ماذا تحتاج لتشغيل موقع ويب؟

حتى يعمل الموقع يحتاج إلى:

- Domain Name.
- Server.
- Public Static IP Address (إذا كان الخادم مستضافًا لديك).

أو يمكن استضافة الموقع لدى شركة استضافة توفر الخادم وعنوان IP.

---

## 📧 استخدام Domain Name

لا يقتصر استخدام Domain Name على المواقع فقط.

يمكن أيضًا استخدامه لإنشاء عناوين بريد إلكتروني مثل:

```text
abuhadhoud@programmingadvices.com
```

---

## 🏛️ بعض الامتدادات لها استخدامات خاصة

على سبيل المثال:

```text
.gov
```

يستخدم عادةً للجهات الحكومية ويتطلب إجراءات خاصة للحصول عليه.

---

## 🔑 الخلاصة

- **Domain Name** هو اسم سهل التذكر يرتبط بعنوان IP.
- يستخدم بدلاً من كتابة عنوان IP مباشرة.
- كل Domain Name فريد ولا يمكن تسجيله مرتين.
- يمكن شراء Domain Name من مواقع مثل:
  - Namecheap
  - GoDaddy
  - Domain.com
- بعد شراء النطاق يتم ربطه بعنوان IP الخاص بالخادم.
- يمكن استخدام Domain Name للمواقع والبريد الإلكتروني.

# What is Domain Name? From Where to Get One?

---

## 📝 Introduction

This lesson explains:

- What a **Domain Name** is.
- The relationship between a Domain Name and an **IP Address**.
- Why Domain Names are used.
- How to purchase a Domain Name.
- Popular Domain Name registrars.

---

## 🌐 Quick Review

Previously learned concepts:

- Every website runs on a **Server** with an **IP Address**.
- Browsers use a **URL** to access websites.
- Websites are ultimately reached through their IP addresses.

---

## 🎯 What is a Domain Name?

A **Domain Name** is:

> **An easy-to-remember name associated with an IP Address on the Internet.**

Instead of typing an IP Address, users can type a memorable name such as:

```text
programmingadvices.com
```

---

## 💡 Why Do We Use Domain Names?

IP addresses are difficult to remember.

Example:

```text
104.19.238.117
```

Instead of remembering this number, users simply type:

```text
programmingadvices.com
```

to reach the same server.

---

## 📱 A Simple Analogy

A Domain Name works like a contact name on a phone.

Instead of memorizing someone's phone number, you remember their name.

Similarly:

- Users remember the Domain Name.
- The system uses the associated IP Address.

---

## 🔗 Relationship Between a Domain Name and an IP Address

Every Domain Name is associated with a specific IP Address.

For example:

```text
facebook.com
```

is associated with Facebook's servers.

Likewise:

```text
programmingadvices.com
```

points to the IP Address of its web server.

---

## 🌍 Common Domain Extensions

Popular extensions include:

- .com
- .net
- .org
- .info
- .business
- .me
- .gov
- .edu

The most common extension is:

```text
.com
```

---

## 🔑 Domain Names Must Be Unique

Every Domain Name must be unique.

If someone has already registered a name, it cannot be registered again.

Examples:

```text
facebook.com
```

and

```text
programmingadvices.com
```

are already registered.

---

## 🛒 How to Get a Domain Name

The general process is:

1. Choose a Domain Name.
2. Check whether it is available.
3. Purchase it if available.
4. Link it to your server's IP Address.

---

## 💰 Domain Name Cost

A Domain Name typically costs around:

- **$10–11 per year**

depending on the extension and registrar.

---

## 🌐 Domain Registrars

Popular Domain registrars include:

- Namecheap
- GoDaddy
- Domain.com

These services allow users to:

- Search for available names.
- Check registration status.
- Purchase available domains.

---

## 📍 What Happens After Buying a Domain?

Buying a Domain Name only reserves the name.

It must then be linked to a server's IP Address so users can reach the website using the Domain Name.

---

## 🖥️ What Is Needed to Host a Website?

To host a website, you generally need:

- A Domain Name.
- A Server.
- A Public Static IP Address (when hosting the server yourself).

Alternatively, a hosting provider can supply both the server and its IP Address.

---

## 📧 Domain Names for Email

A Domain Name can also be used for email addresses, such as:

```text
abuhadhoud@programmingadvices.com
```

---

## 🏛️ Special Domain Extensions

Some extensions have special purposes.

For example:

```text
.gov
```

is generally reserved for government organizations and follows special registration procedures.

---

## 🔑 Summary

- A **Domain Name** is an easy-to-remember name associated with an IP Address.
- It replaces difficult-to-remember IP addresses.
- Every Domain Name must be unique.
- Domain Names can be purchased from services such as:
  - Namecheap
  - GoDaddy
  - Domain.com
- After registration, the Domain Name is linked to a server's IP Address.
- Domain Names can be used for websites and email addresses.
