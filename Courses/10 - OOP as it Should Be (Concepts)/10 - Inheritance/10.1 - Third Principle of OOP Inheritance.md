# Third Principle/Concept of OOP: Inheritance

---

## 📝 مقدمة

`Inheritance` هو المبدأ الثالث من مبادئ البرمجة كائنية التوجه.

الفكرة الأساسية هي إعادة استخدام الكود الموجود في `Class` أخرى بدل إعادة كتابته. إذا كان `Employee` في الأصل `Person`، فيمكن لـ `Employee` أن يرث الكود الموجود في `Person` ثم يضيف الأعضاء الخاصة به فقط.

---

## 🧠 مراجعة سريعة

لدينا `Class Person` تحتوي على البيانات والدوال و`Properties` الخاصة بها.

إذا كانت `Employee` تحتاج إلى معظم هذه الأعضاء، يمكنها أن ترثها بدل إعادة كتابتها، ثم تضيف الأعضاء الخاصة بها.

---

## 🎯 تعريف: Inheritance

> **Inheritance (الوراثة)**
>
> آلية تسمح لـ `Class` بأن ترث الكود الموجود في `Class` أخرى، ثم تضيف الأعضاء الخاصة بها بدل إعادة كتابة الكود الموروث.

---

## ⚙️ كيف تعمل Inheritance

لنفترض أن لدينا `Person` تحتوي على أعضاء مثل:

`ID` و`FirstName` و`LastName` و`FullName` و`Email` و`Phone` و`SendEmail` و`SendSMS` و`Print`.

ثم لدينا `Employee` تحتاج إلى معظم هذه الأعضاء، بالإضافة إلى:

- `Title`
- `Salary`
- `Department`

بدل إعادة كتابة أعضاء `Person` مرة أخرى داخل `Employee`، نستخدم `Inheritance`.

بهذه الطريقة تستفيد `Employee` من الأعضاء الموروثة، ونكتب فقط الأشياء المختلفة الخاصة بها.

---

## 💡 لماذا نستخدم Inheritance؟

الهدف الأساسي هو تقليل إعادة كتابة الكود وتوفير الوقت والجهد.

إذا كانت دالة مشتركة مثل `SendEmail` مكتوبة في أكثر من `Class`، فإن تعديلها يتطلب تعديل أكثر من مكان.

مع `Inheritance`، يبقى الكود المشترك في `Person`. وإذا احتجنا إلى تعديله، نعدله في مكان واحد، وتستفيد منه الكلاسات التي ترث منه.

وهذا يزيد `Reusability` ويسهّل صيانة الكود.

---

## ⚙️ Syntax إنشاء Derived Class

صيغة إنشاء `Derived Class` هي:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class DerivedClass : public BaseClass
{
    // new members
};
```

</div>

في المثال:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsEmployee : public clsPerson
{
    // Employee members
};
```

</div>

هذا يعني أن `clsEmployee` هي `Derived Class`، وأن `clsPerson` هي `Base Class`، وأن الوراثة هنا تستخدم `public`.

---

## 💻 مثال: `clsEmployee` ترث `clsPerson`

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

using namespace std;

class clsPerson
{

private:
    int _ID;
    string _FirstName;
    string _LastName;
    string _Email;

        string LastName,
        string Email,
        string Phone)
    {
        _ID = ID;
        _FirstName = FirstName;
        _LastName = LastName;
        _Email = Email;
        _Phone = Phone;
    }

    //Read Only Property
    int ID()
    {
        return _ID;
    }

    //Property Set
    void setFirstName(string FirstName)
    {
        _FirstName = FirstName;
    }

    //Property Get
    string FirstName()
    {
        return _FirstName;
    }

    //Property Set
    void setLastName(string LastName)
    {
        _LastName = LastName;
    }

    //Property Get
    string LastName()
    {
        return _LastName;
    }

    //Property Set
    void setEmail(string Email)
    {
        _Email = Email;
    }

    //Property Get
    string Email()
    {
        return _Email;
    }

    //Property Set
    void setPhone(string Phone)
    {
        _Phone = Phone;
    }

    //Property Get
    string Phone()
    {
        return _Phone;
    }

    string FullName()
    {
        return _FirstName + " " + _LastName;
    }

    void Print()
    {
        cout << "\nInfo:";
        cout << "\n___________________";
        cout << "\nID       : " << _ID;
        cout << "\nFirstName: " << _FirstName;
        cout << "\nLastName : " << _LastName;
        cout << "\nFull Name: " << FullName();
        cout << "\nEmail    : " << _Email;
        cout << "\nPhone    : " << _Phone;
        cout << "\n___________________\n";
    }

    void SendEmail(string Subject, string Body)
    {
        cout << "\nThe following message sent successfully to email: " << _Email;
        cout << "\nSubject: " << Subject;
        cout << "\nBody: " << Body << endl;
    }

    void SendSMS(string TextMessage)
    {
        cout << "\nThe following SMS sent successfully to phone: " << _Phone;
        cout << "\n" << TextMessage << endl;
    }
};

class clsEmployee : public clsPerson
{

private:
    string _Title;
    string _Department;
    float _Salary;

public:

    //Property Set
    void setTitle(string Title)
    {
        _Title = Title;
    }

    //Property Get
    string Title()
    {
        return _Title;
    }

    //Property Set
    void setDepartment(string Department)
    {
        _Department = Department;
    }

    //Property Get
    string Department()
    {
        return _Department;
    }

    //Property Set
    void setSalary(float Salary)
    {
        _Salary = Salary;
    }

    //Property Get
    float Salary()
    {
        return _Salary;
    }
};

int main()
{
    clsEmployee Employee1;

    Employee1.setFirstName("Mohammed");
    Employee1.setLastName("Abu-Hadhoud");
    Employee1.setEmail("a@a.com");
    Employee1.Print();
    Employee1.SendEmail("Hi", "How are you?");

    Employee1.setSalary(5000);

    cout << "Salary is: " << Employee1.Salary();

    //Calling the print will not print anything from derived class, only base class
    //therfore the print method will not serve me here, this is a problem will be solved in the next lecture.
    Employee1.Print();

    system("pause>0");
    return 0;
}

```

</div>

في هذا المثال، `clsEmployee` ترث `clsPerson`.

عند إنشاء:

`clsEmployee Employee1;`

يمكن استخدام الأعضاء الموروثة مثل `setFirstName()` و`setLastName()` و`setEmail()` و`Print()` و`SendEmail()`.

كما يمكن استخدام الأعضاء الخاصة بـ `clsEmployee` مثل `setSalary()` و`Salary()`.

---

## 📌 أسماء الكلاسات في Inheritance

### `Super Class` / `Base Class`

هي الـ `Class` الأصلية التي يتم أخذ الكود منها.

في المثال:

`clsPerson`

هي الـ `Super Class` أو `Base Class`.

### `Sub Class` / `Derived Class`

هي الـ `Class` التي ترث من الـ `Base Class`.

في المثال:

`clsEmployee`

هي الـ `Sub Class` أو `Derived Class`.

---

## 📌 ماذا يرث `Employee`؟

عندما يرث `Employee` من `Person`، يمكنه الاستفادة من الأعضاء الموجودة في `Person`.

لذلك يمكن استخدام:

`FirstName` و`LastName` و`FullName` و`Email` و`Phone` و`SendEmail` و`SendSMS` و`Print`

دون إعادة كتابة هذه الأعضاء داخل `Employee`.

أما `Title` و`Salary` و`Department` فهي الأعضاء الخاصة بـ `Employee`.

---

## 📌 إعادة استخدام الكود

إذا أضفنا لاحقًا دالة مثل `SendFax` إلى `Person`، فإن الكلاسات التي ترث من `Person` يمكنها الاستفادة منها دون إعادة كتابة الدالة داخل كل `Sub Class`.

وبذلك يمكن تطوير `Base Class` مرة واحدة والاستفادة من التعديل في الكلاسات الموروثة.

---

## ⚙️ Inheritance والـ Constructor

عند إنشاء `Object` من `Employee`، يجب أن يمكن إنشاء الجزء الموروث من `Person` أيضًا.

لذلك يحتوي `clsPerson` هنا على `Default Constructor`:

`clsPerson()`

وهو موجود مؤقتًا حتى يمكن إنشاء `Employee` بهذه الطريقة.

أما التعامل مع `Parameterized Constructor` مع `Inheritance` فسيأتي في درس منفصل.

---

## ⚠️ ملاحظات

- `Inheritance` تقلل إعادة كتابة الكود.
- `Employee` يمكن أن ترث من `Person` عندما تكون `Employee` في الأصل `Person`.
- الكود الموروث لا يحتاج إلى نسخه داخل `Sub Class`.
- `Super Class` و`Base Class` اسمان للكلاس الأصلية.
- `Sub Class` و`Derived Class` اسمان للكلاس التي ترث.
- يمكن للكلاس الوارث إضافة أعضاء جديدة خاصة بها.
- تعديل الكود المشترك في `Base Class` يجعل التعديل متاحًا للكلاسات التي ترث منها.
- يجب الانتباه إلى `Constructor` الخاص بالكلاس الأصلية عند استخدام `Inheritance`.
- تفاصيل `Parameterized Constructor` مع `Inheritance` ستأتي لاحقًا.

---

## 📚 المصطلحات

| المصطلح | المعنى |
|---|---|
| Inheritance | وراثة الكود من `Class` إلى `Class` أخرى |
| Super Class | الكلاس الأصلية التي ترث منها `Sub Class` |
| Base Class | اسم آخر للكلاس الأصلية |
| Sub Class | الكلاس التي ترث من `Base Class` |
| Derived Class | اسم آخر للكلاس الوارثة |
| `public` Inheritance | نوع الوراثة الظاهر في الصيغة المستخدمة  |

بدل كتابة نفس الكود في `Person` و`Employee`، نضع الكود المشترك في `Person` ونجعل `Employee` ترث منه.

وبذلك تستفيد `Employee` من الأعضاء الموجودة في `Person` وتضيف فقط الأعضاء الخاصة بها مثل `Title` و`Salary` و`Department`.

---

## 🔑 ملخص

- `Inheritance` هو المبدأ الثالث من مبادئ OOP في هذا الجزء.
- يسمح بإعادة استخدام كود موجود في `Base Class`.
- `Employee` يمكن أن ترث من `Person`.
- الأعضاء المشتركة لا تحتاج إلى إعادة كتابتها في `Employee`.
- `Employee` تضيف فقط الأعضاء الخاصة بها.
- `Person` تسمى `Super Class` أو `Base Class`.
- `Employee` تسمى `Sub Class` أو `Derived Class`.
- تعديل الكود المشترك في `Base Class` يوفر إعادة التعديل في أماكن متعددة.
- يجب الانتباه إلى `Constructor` عند استخدام `Inheritance`.

## 📝 Introduction

`Inheritance` is the third Object-Oriented Programming principle introduced here.

The main idea is to reuse code from another `Class` instead of writing the same code again. If `Employee` is a `Person`, `Employee` can inherit the code in `Person` and then add its own members.

---

## 🧠 Quick Recap

We already have a `Person` class with its data, functions, and `Properties`.

If `Employee` needs most of these members, it can inherit them instead of writing them again, then add its own members.

---

## 🎯 Definition: Inheritance

> **Inheritance**
>
> A mechanism that allows one `Class` to inherit code from another `Class` and then add its own members instead of rewriting the inherited code.

---

## ⚙️ How Inheritance Works

Suppose we have a `Person` with members such as:

`ID`, `FirstName`, `LastName`, `FullName`, `Email`, `Phone`, `SendEmail`, `SendSMS`, and `Print`.

Then we have an `Employee` that needs most of these members, plus:

- `Title`
- `Salary`
- `Department`

Instead of writing the `Person` members again inside `Employee`, we use `Inheritance`.

`Employee` can use the inherited members and we only write the new members that are different.

---

## 💡 Why Use Inheritance?

The main goal is to reduce repeated code and save time and effort.

If a shared function such as `SendEmail` is copied into many classes, changing it means changing it in many places.

With `Inheritance`, the shared code stays in `Person`. We change it in one place, and the classes that inherit from it can use the change.

This improves `Reusability` and makes maintenance easier.

---

## ⚙️ Syntax for Creating a Derived Class

The syntax is:

```cpp
class DerivedClass : public BaseClass
{
    // new members
};
```

In this example:

```cpp
class clsEmployee : public clsPerson
{
    // Employee members
};
```

This means `clsEmployee` is the `Derived Class`, `clsPerson` is the `Base Class`, and the inheritance here uses `public`.

## 📌 Class Names in Inheritance

### `Super Class` / `Base Class`

The original `Class` that provides the inherited code.

In the example:

`clsPerson`

is the `Super Class` or `Base Class`.

### `Sub Class` / `Derived Class`

The `Class` that inherits from the `Base Class`.

In the example:

`clsEmployee`

is the `Sub Class` or `Derived Class`.

---

## 📌 What Does `Employee` Inherit?

When `Employee` inherits from `Person`, it can use members already available in `Person`.

So it can use:

`FirstName`, `LastName`, `FullName`, `Email`, `Phone`, `SendEmail`, `SendSMS`, and `Print`

without rewriting them inside `Employee`.

`Title`, `Salary`, and `Department` are the members added for `Employee`.

---

## 📌 Code Reusability

If we later add a function such as `SendFax` to `Person`, classes that inherit from `Person` can use it without rewriting it in every `Sub Class`.

So the `Base Class` can be changed once and the derived classes can use the updated code.

---

## ⚙️ Inheritance and Constructors

When we create an `Object` of `Employee`, the inherited `Person` part must also be created.

So `clsPerson` has this `Default Constructor`:

`clsPerson()`

It is included here temporarily so `Employee` can be created this way.

The details of `Parameterized Constructor` with `Inheritance` will be handled in a separate lesson.

---

## ⚠️ Notes

- `Inheritance` reduces repeated code.
- `Employee` can inherit from `Person` when an `Employee` is a `Person`.
- Inherited code does not need to be copied into the `Sub Class`.
- `Super Class` and `Base Class` are names for the original class.
- `Sub Class` and `Derived Class` are names for the class that inherits.
- The derived class can add its own new members.
- Changing shared code in the `Base Class` makes the change available to classes that inherit from it.
- We must pay attention to the `Constructor` of the base class when using `Inheritance`.
- The details of `Parameterized Constructor` with `Inheritance` will come later.

---

## 📚 Terminology

| Term | Meaning |
|---|---|
| Inheritance | Reusing code from one `Class` in another `Class` |
| Super Class | The original class that the `Sub Class` inherits from |
| Base Class | Another name for the original class |
| Sub Class | The class that inherits from the `Base Class` |
| Derived Class | Another name for the class that inherits |
| `public` Inheritance | The inheritance form shown in the syntax used in the recording |

---

## 💡 Key Idea

Instead of writing the same code in `Person` and `Employee`, we keep the shared code in `Person` and make `Employee` inherit from it.

Then `Employee` can use the members from `Person` and add only its own members such as `Title`, `Salary`, and `Department`.

---

## 🔑 Summary

- `Inheritance` is the third Object-Oriented Programming principle in this part.
- It allows us to reuse code from a `Base Class`.
- `Employee` can inherit from `Person`.
- Shared members do not need to be rewritten in `Employee`.
- `Employee` adds only its own members.
- `Person` is called the `Super Class` or `Base Class`.
- `Employee` is called the `Sub Class` or `Derived Class`.
- Changing shared code in the `Base Class` avoids changing copied code in many places.
- We must pay attention to the `Constructor` when using `Inheritance`.
