# Parameterized Constructor with Inheritance

---

## 📝 مقدمة

عند وراثة `clsEmployee` من `clsPerson`، يصبح لدينا `Constructor` في الكلاس الأصلية يحتاج إلى بيانات خاصة بـ `Person`.

في هذا الدرس، نستخدم `Constructor` الخاص بـ `Employee` لاستقبال بيانات `Person` وبيانات `Employee`، ثم نمرر بيانات `Person` إلى `Constructor` الخاص بـ `clsPerson`.

---

## 🧠 مراجعة سريعة

`clsPerson` لديها `Parameterized Constructor` يحتاج إلى:

`ID` و`FirstName` و`LastName` و`Email` و`Phone`.

و`clsEmployee` لديها بيانات إضافية:

`Title` و`Department` و`Salary`.

لذلك يجب أن يستقبل `Constructor` الخاص بـ `Employee` البيانات المطلوبة للكلاسين.

---

## 🎯 تعريف: Parameterized Constructor with Inheritance

> **Parameterized Constructor with Inheritance**
>
> `Constructor` في الـ `Derived Class` يستقبل بيانات الـ `Base Class` وبياناته الخاصة، ثم يمرر بيانات الـ `Base Class` إلى `Constructor` الخاص بها.

---

## ⚙️ لماذا نحتاج إلى ذلك؟

الـ `Base Class` هنا لا تحتوي على `Default Constructor`.

لذلك يجب إرسال بيانات `Person` عند إنشاء `Employee`.

في الوقت نفسه، تحتاج `Employee` إلى `Title` و`Department` و`Salary`، لذلك يستقبل `Constructor` الخاص بها جميع هذه البيانات.

---

## ⚙️ Constructor Initializer List

يتم تمرير بيانات الـ `Base Class` باستخدام الجزء الذي يأتي بعد `:` في الـ `Constructor`.

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
clsEmployee(
    int ID,
    string FirstName,
    string LastName,
    string Email,
    string Phone,
    string Title,
    string Department,
    float Salary)
    : clsPerson(ID, FirstName, LastName, Email, Phone)
{
    _Title = Title;
    _Department = Department;
    _Salary = Salary;
}
```

</div>

هنا يتم إرسال بيانات `Person` إلى `(...)clsPerson`، بينما تتم تهيئة بيانات `Employee` داخل جسم `Constructor`.

---

## 💻 مثال: `clsEmployee` مع Parameterized Constructor

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
#include <iostream>

using namespace std;

class clsPerson
{
private:
    int _ID;
    string _FirstName;
    string _LastName;
    string _Email;
    string _Phone;

public:
    clsPerson(
        int ID,
        string FirstName,
        string LastName,
        string Email,
        string Phone)
    {
        _ID = ID;
        _FirstName = FirstName;
        _LastName = LastName;
        _Email = Email;
        _Phone = Phone;
    }

    int ID()
    {
        return _ID;
    }

    void setFirstName(string FirstName)
    {
        _FirstName = FirstName;
    }

    string FirstName()
    {
        return _FirstName;
    }

    void setLastName(string LastName)
    {
        _LastName = LastName;
    }

    string LastName()
    {
        return _LastName;
    }

    void setEmail(string Email)
    {
        _Email = Email;
    }

    string Email()
    {
        return _Email;
    }

    void setPhone(string Phone)
    {
        _Phone = Phone;
    }

    string Phone()
    {
        return _Phone;
    }

    string FullName()
    {
        return _FirstName + " " + _LastName;
    }

    void Print()
    {
        cout << "\nInfo:";
        cout << "\n___________________";
        cout << "\nID       : " << _ID;
        cout << "\nFirstName: " << _FirstName;
        cout << "\nLastName : " << _LastName;
        cout << "\nFull Name: " << FullName();
        cout << "\nEmail    : " << _Email;
        cout << "\nPhone    : " << _Phone;
        cout << "\n___________________\n";
    }

    void SendEmail(string Subject, string Body)
    {
        cout << "\nThe following message sent successfully to email: " << _Email;
        cout << "\nSubject: " << Subject;
        cout << "\nBody: " << Body << endl;
    }

    void SendSMS(string TextMessage)
    {
        cout << "\nThe following SMS sent successfully to phone: " << _Phone;
        cout << "\n" << TextMessage << endl;
    }
};

class clsEmployee : public clsPerson
{
private:
    string _Title;
    string _Department;
    float _Salary;

public:
    clsEmployee(
        int ID,
        string FirstName,
        string LastName,
        string Email,
        string Phone,
        string Title,
        string Department,
        float Salary)
        : clsPerson(ID, FirstName, LastName, Email, Phone)
    {
        _Title = Title;
        _Department = Department;
        _Salary = Salary;
    }

    void setTitle(string Title)
    {
        _Title = Title;
    }

    string Title()
    {
        return _Title;
    }

    void setDepartment(string Department)
    {
        _Department = Department;
    }

    string Department()
    {
        return _Department;
    }

    void setSalary(float Salary)
    {
        _Salary = Salary;
    }

    float Salary()
    {
        return _Salary;
    }
};

int main()
{
    clsEmployee Employee1(
        10,
        "Mohammed",
        "Abu-Hadhoud",
        "A@a.com",
        "8298982",
        "CEO",
        "ProgrammingAdvices",
        5000);

    Employee1.Print();

    cout << "\n" << Employee1.Title() << endl;
    cout << "\n" << Employee1.Department() << endl;
    cout << "\n" << Employee1.Salary() << endl;

    system("pause>0");
    return 0;
}
```

</div>

عند إنشاء `Employee1`، يتم إرسال ثمانية قيم.

الخمس الأولى تخص `Person` وتذهب إلى `clsPerson`، والثلاث الأخيرة تخص `Employee` وتتم تهيئتها داخل `clsEmployee`.

---

## 📌 توزيع الـ Parameters

| بيانات `Person` | بيانات `Employee` |
|---|---|
| `ID` | `Title` |
| `FirstName` | `Department` |
| `LastName` | `Salary` |
| `Email` | |
| `Phone` | |

بيانات `Person` يتم تمريرها إلى الـ `Base Constructor`.

وبيانات `Employee` يتم تخزينها داخل الـ `Derived Class`.

---

## ⚙️ ماذا يحدث عند إنشاء `Employee1`؟

عند كتابة:
<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

`clsEmployee Employee1(10, "Mohammed", "Abu-Hadhoud", "A@a.com", "8298982", "CEO", "ProgrammingAdvices", 5000);`
</div>
يتم إنشاء `Object` يحتوي على البيانات المطلوبة للكلاسين.

البيانات الخاصة بـ `Person` تذهب إلى `clsPerson`، والبيانات الخاصة بـ `Employee` تذهب إلى `clsEmployee`.

---

## 📌 لماذا لا تطبع `()Print` بيانات Employee؟

الدالة `()Print` موجودة داخل `clsPerson`، لذلك تطبع بيانات `Person` فقط.

وجود `Title` و`Department` و`Salary` داخل الـ `Object` لا يجعل `()Print` تطبعها تلقائيًا.

الدالة الحالية لا تحتوي على كود لطباعة هذه الأعضاء. سيتم معالجة هذه المشكلة في الدرس التالي.

---

## 📚 المصطلحات

| المصطلح | المعنى |
|---|---|
| Constructor Initializer List | الجزء الذي يأتي بعد `:` في الـ `Constructor` لتمرير تهيئة الـ `Base Class` هنا |
| `(...)clsPerson` | استدعاء `Constructor` الخاص بالـ `Base Class` |
| Derived Constructor | `Constructor` الخاص بالكلاس الوارثة |
| Base Constructor | `Constructor` الخاص بالكلاس الأصلية |

---

## ⚠️ ملاحظات

- `clsEmployee` تحتاج إلى `Constructor` لأن `clsPerson` لديها `Parameterized Constructor`.
- بيانات `Person` يجب تمريرها إلى `(...)clsPerson`.
- بيانات `Employee` تتم تهيئتها داخل `clsEmployee`.
- الصيغة الأساسية هي:
  ` clsPerson(ID, FirstName, LastName, Email, Phone) :`
- `Constructor` الخاص بـ `Derived Class` يمكن أن يستقبل بيانات للكلاس الأصلية وبياناته الخاصة.
- `()Print` الموروثة لا تطبع الأعضاء الجديدة الخاصة بـ `Employee`.

---

## 💡 الفكرة الأساسية

عندما تحتوي `Base Class` على `Parameterized Constructor`، يمرر `Derived Class` البيانات المطلوبة إليه باستخدام `Constructor Initializer List`.

في المثال:

`clsEmployee(...) : clsPerson(ID, FirstName, LastName, Email, Phone)`

البيانات الخاصة بـ `Person` تذهب إلى `clsPerson`، بينما تتم تهيئة `Title` و`Department` و`Salary` داخل `clsEmployee`.

---

## 🔑 ملخص

- `Derived Class` يمكنها استقبال parameters للكلاس الأصلية ولأعضائها الخاصة.
- بيانات `Base Class` تذهب إلى `Base Constructor`.
- يتم ذلك باستخدام `Constructor Initializer List`.
- الصيغة هي:
  `clsPerson(ID, FirstName, LastName, Email, Phone) :`
- `Title` و`Department` و`Salary` تتم تهيئتها داخل `clsEmployee`.
- يمكن إنشاء `Employee` ممتلئًا بجميع البيانات المطلوبة في خطوة واحدة.
- `()Print` الموروثة لا تطبع بيانات `Employee` الإضافية.

## 📝 Introduction

`clsPerson` has a `Parameterized Constructor` that needs `Person` data.

When `clsEmployee` inherits from `clsPerson`, the `Employee` constructor must receive the `Person` data and pass it to the `clsPerson` constructor. It must also initialize the data that belongs to `Employee`.

---

## 🧠 Quick Recap

`clsEmployee` inherits from `clsPerson`.

`Person` needs:

`ID`, `FirstName`, `LastName`, `Email`, and `Phone`.

`Employee` also needs:

`Title`, `Department`, and `Salary`.

So the `Employee` constructor receives all the required data.

---

## 🎯 Definition: Parameterized Constructor with Inheritance

> **Parameterized Constructor with Inheritance**
>
> A constructor in the `Derived Class` that receives data for the `Base Class` and for the `Derived Class`, then passes the `Base Class` data to its constructor.

---

## ⚙️ Why Do We Need This?

The `Base Class` here does not have a `Default Constructor`.

So the `clsPerson` part cannot be created without `ID`, `FirstName`, `LastName`, `Email`, and `Phone`.

At the same time, `Employee` needs `Title`, `Department`, and `Salary`.

So the `Employee` constructor receives all of these values.

---

## ⚙️ Constructor Initializer List

The `Base Class` data is passed using the part after `:` in the constructor.

```cpp
clsEmployee(
    int ID,
    string FirstName,
    string LastName,
    string Email,
    string Phone,
    string Title,
    string Department,
    float Salary)
    : clsPerson(ID, FirstName, LastName, Email, Phone)
{
    _Title = Title;
    _Department = Department;
    _Salary = Salary;
}
```

Here, the `Person` data goes to `clsPerson(...)`, while the `Employee` data is initialized inside the constructor body.

---

---

## 📌 Parameter Distribution

| `Person` Data | `Employee` Data |
|---|---|
| `ID` | `Title` |
| `FirstName` | `Department` |
| `LastName` | `Salary` |
| `Email` | |
| `Phone` | |

The `Person` data is passed to the `Base Constructor`.

The `Employee` data is stored inside the `Derived Class`.

---

## ⚙️ What Happens When `Employee1` Is Created?

When we write:

`clsEmployee Employee1(10, "Mohammed", "Abu-Hadhoud", "A@a.com", "8298982", "CEO", "ProgrammingAdvices", 5000);`

an `Object` is created with the required data for both classes.

The `Person` data goes to `clsPerson`, and the `Employee` data goes to `clsEmployee`.

---

## 📌 Why Does `Print()` Not Show the Employee Data?

The `Print()` function is inside `clsPerson`, so it prints only `Person` data.

Having `Title`, `Department`, and `Salary` inside the `Object` does not make `Print()` print them automatically.

The current function does not contain code for these members. This problem will be handled in the next lesson.

---

## 📚 Terminology

| Term | Meaning |
|---|---|
| Constructor Initializer List | The part after `:` in the constructor used here to pass data to the `Base Class` constructor |
| `clsPerson(...)` | A call to the `Base Class` constructor |
| Derived Constructor | The constructor of the derived class |
| Base Constructor | The constructor of the base class |

---

## ⚠️ Notes

- `clsEmployee` needs a constructor because `clsPerson` has a `Parameterized Constructor`.
- The `Person` data must be passed to `clsPerson(...)`.
- The `Employee` data is initialized inside `clsEmployee`.
- The basic syntax is:
  `: clsPerson(ID, FirstName, LastName, Email, Phone)`
- The `Derived Class` constructor can receive data for the base class and for its own members.
- The inherited `Print()` does not print the new `Employee` members.

---

## 💡 Key Idea

When the `Base Class` has a `Parameterized Constructor`, the `Derived Class` passes the required data to it using the `Constructor Initializer List`.

In this example:

`clsEmployee(...) : clsPerson(ID, FirstName, LastName, Email, Phone)`

sends the `Person` data to the `clsPerson` constructor, while `Title`, `Department`, and `Salary` are initialized inside `clsEmployee`.

---

## 🔑 Summary

- The `Derived Class` can receive parameters for the base class and for its own members.
- The `Base Class` data goes to the `Base Constructor`.
- This is done using the `Constructor Initializer List`.
- The basic syntax is:
  `: clsPerson(ID, FirstName, LastName, Email, Phone)`
- `Title`, `Department`, and `Salary` are initialized inside `clsEmployee`.
- We can create an `Employee` with all required data in one step.
- The inherited `Print()` does not print the extra `Employee` data.
