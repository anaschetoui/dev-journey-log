# Visibility Modes

---

## 📝 مقدمة

عندما نستخدم `Inheritance`، لا نحدد فقط أي `Class` ترث من أخرى، بل نحدد أيضًا **كيف تظهر الأعضاء الموروثة داخل الـ `Derived Class`**.

هذا يسمى `Visibility Mode`.

الأنواع التي نستخدمها هنا هي:

- `public`
- `protected`
- `private`

---

## 🧠 مراجعة سريعة

لدينا ثلاثة `Access Specifiers` داخل الـ `Class`:

`private` و`protected` و`public`.

لكن في الوراثة يوجد أيضًا شيء آخر يسمى `Visibility Mode`، ويظهر في صيغة الوراثة:

`public` أو `protected` أو `private`.

---

## 🎯 تعريف: Visibility Mode

> **Visibility Mode**
>
> طريقة تحدد مستوى ظهور الأعضاء `public` و`protected` الموروثة داخل الـ `Derived Class`، وما إذا كانت تبقى `public` أو تصبح `protected` أو `private`.

الأعضاء `private` في الـ `Base Class` لا تصبح متاحة للـ `Derived Class` بسبب تغيير الـ `Visibility Mode`.

---

## ⚙️ Public Inheritance

عندما نكتب:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsEmployee : public clsPerson
{
};
```

</div>

فإن الوراثة تكون `public`.

في هذه الحالة:

| عضو الـ Base Class | داخل الـ Derived Class |
|---|---|
| `public` | `public` |
| `protected` | `protected` |
| `private` | غير متاح مباشرة |

أي أن `public` يبقى `public`، و`protected` يبقى `protected`.

ولهذا يمكن أن تصل الأعضاء `public` من خارج الـ `Derived Class`، بينما تبقى الأعضاء `protected` متاحة للـ `Derived Class` فقط ومن يرث منها وفق مستوى الوصول.

---

## ⚙️ Protected Inheritance

عندما نكتب:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsEmployee : protected clsPerson
{
};
```

</div>

تصبح الأعضاء الموروثة كالتالي:

| عضو الـ Base Class | داخل الـ Derived Class |
|---|---|
| `public` | `protected` |
| `protected` | `protected` |
| `private` | غير متاح مباشرة |

أي أن `public` لم يعد `public`.

بل يتحول إلى `protected`.

أما `protected` فيبقى `protected`.

---

## 📌 ماذا يعني Protected Inheritance؟

إذا كانت `Base Class` تحتوي على `public` member، ثم ورثناها باستخدام `protected`، فلن يبقى هذا العضو متاحًا مباشرة من الخارج من خلال الـ `Object`.

لكن يبقى متاحًا داخل الـ `Derived Class`، ويمكن للكلاسات التي ترث من هذه الـ `Derived Class` الوصول إليه كـ `protected`.

لذلك يمكن استخدام `protected Inheritance` عندما نريد الاحتفاظ بالأعضاء الموروثة للاستخدام داخل سلسلة الوراثة، دون جعلها `public` للمستخدم الخارجي.

---

## ⚙️ Private Inheritance

عندما نكتب:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsEmployee : private clsPerson
{
};
```
</div>

تصبح الأعضاء الموروثة كالتالي:

| عضو الـ Base Class | داخل الـ Derived Class |
|---|---|
| `public` | `private` |
| `protected` | `private` |
| `private` | غير متاح مباشرة |

أي أن `public` و`protected` يتحولان إلى `private` داخل الـ `Derived Class`.

---

## 📌 ماذا يعني Private Inheritance؟

عندما نستخدم `private Inheritance`، يمكن للـ `Derived Class` استخدام الأعضاء الموروثة داخلها، لكن هذه الأعضاء لا تبقى متاحة من الخارج.

والأهم أن الكلاس التي ترث لاحقًا من هذه الـ `Derived Class` لن تحصل على هذه الأعضاء كأعضاء `protected` أو `public`.

يمكن للكلاس أن تستفيد من الوراثة داخليًا، لكن لا تكشف الأعضاء الموروثة للمستويات التالية أو للكود الخارجي.

---

## 📌 ماذا يحدث في Multilevel Inheritance؟

يمكن أن يكون لدينا أكثر من مستوى:

`Base → Derived → Derived2`

والـ `Visibility Mode` في كل مستوى يؤثر في المستوى الذي يليه.

مثلًا، إذا كانت لدينا:

`public` inheritance

فإن:

`public → public`

و:

`protected → protected`

أما إذا استخدمنا:

`protected` inheritance

فإن:

`public → protected`

و:

`protected → protected`

أما إذا استخدمنا:

`private` inheritance

فإن:

`public → private`

و:

`protected → private`

---

## 💻 مثال: مستوى الوراثة

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class Base
{
public:
    int PublicMember;

protected:
    int ProtectedMember;

private:
    int PrivateMember;
};

class Derived : public Base
{
};

class Derived2 : public Derived
{
};
```

</div>

في حالة `public inheritance`، يبقى `PublicMember` متاحًا كـ `public`، ويبقى `ProtectedMember` كـ `protected`.

أما `PrivateMember` فلا يصبح متاحًا للـ `Derived Class`.

---

## 📌 الفرق بين Access Specifier و Visibility Mode

`Access Specifier` هو الكلمة الموجودة **داخل الـ Class** مثل:

`private` و`protected` و`public`.

أما `Visibility Mode` فهو الكلمة التي تأتي **في صيغة الوراثة** مثل:

`public` أو `protected` أو `private`.

مثال:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsEmployee : public clsPerson
{
};
```

</div>

الكلمة `public` هنا هي `Visibility Mode` للوراثة.

أما إذا كتبنا داخل `Class`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsPerson
{
protected:
    int Var2;
};
```

</div>

فإن `protected` هنا هو `Access Specifier`.

---

## 📚 المصطلحات

| المصطلح | المعنى |
|---|---|
| Visibility Mode | الطريقة التي تحدد مستوى ظهور الأعضاء الموروثة |
| Public Inheritance | `public` يبقى `public` و`protected` يبقى `protected` |
| Protected Inheritance | `public` يصبح `protected` و`protected` يبقى `protected` |
| Private Inheritance | `public` و`protected` يصبحان `private` |
| Access Specifier | محدد الوصول داخل الـ `Class` |
| Multilevel Inheritance | وراثة على أكثر من مستوى |

---

## ⚠️ ملاحظات

- `private` في الـ `Base Class` لا يصبح متاحًا للـ `Derived Class` بسبب `Visibility Mode`.
- في `public inheritance`:
  - `public` يبقى `public`.
  - `protected` يبقى `protected`.
- في `protected inheritance`:
  - `public` يصبح `protected`.
  - `protected` يبقى `protected`.
- في `private inheritance`:
  - `public` يصبح `private`.
  - `protected` يصبح `private`.
- الـ `Visibility Mode` يؤثر أيضًا في الكلاس التي ترث لاحقًا من الـ `Derived Class`.
- يمكن استخدام `Visibility Modes` للتحكم في مقدار ما يتم كشفه من الكود الموروث.

---

## 💡 الفكرة الأساسية

الـ `Visibility Mode` يحدد ماذا يحدث للأعضاء `public` و`protected` عندما نرث `Class`.

احفظها بهذه الصورة:

`public inheritance`  
`public → public`  
`protected → protected`

`protected inheritance`  
`public → protected`  
`protected → protected`

`private inheritance`  
`public → private`  
`protected → private`

أما `private` في الـ `Base Class` فلا يكون متاحًا مباشرة للـ `Derived Class`.

---

## 🔑 ملخص

- `Visibility Mode` يحدد مستوى ظهور الأعضاء الموروثة.
- الأنواع هي `public` و`protected` و`private`.
- `public inheritance` يحافظ على `public` و`protected`.
- `protected inheritance` يحول `public` إلى `protected`.
- `private inheritance` يحول `public` و`protected` إلى `private`.
- أعضاء `private` في الـ `Base Class` لا تصبح متاحة للـ `Derived Class`.
- في `Multilevel Inheritance`، ينتقل تأثير مستوى الوراثة إلى المستوى التالي.

## 📝 Introduction

When we use `Inheritance`, we do not only decide which `Class` inherits from another. We also decide **how the inherited members appear inside the `Derived Class`**.

This is called a `Visibility Mode`.

The three modes are:

- `public`
- `protected`
- `private`

---

## 🧠 Quick Recap

We have three `Access Specifiers` inside a `Class`:

`private`, `protected`, and `public`.

In inheritance, there is also another idea called `Visibility Mode`. It appears in the inheritance syntax:

`public`, `protected`, or `private`.

---

## 🎯 Definition: Visibility Mode

> **Visibility Mode**
>
> A mode that controls how inherited `public` and `protected` members appear inside the `Derived Class`, and whether they stay `public`, become `protected`, or become `private`.

`private` members of the `Base Class` do not become available to the `Derived Class` by changing the `Visibility Mode`.

---

## ⚙️ Public Inheritance

When we write:

```cpp
class clsEmployee : public clsPerson
{
};
```

the inheritance is `public`.

In this case:

| Base Class Member | In the Derived Class |
|---|---|
| `public` | `public` |
| `protected` | `protected` |
| `private` | Not directly accessible |

So `public` stays `public`, and `protected` stays `protected`.

This allows the `public` members to remain available from outside the `Derived Class`, while `protected` members remain available to the `Derived Class` and later derived classes according to access rules.

---

## ⚙️ Protected Inheritance

When we write:

```cpp
class clsEmployee : protected clsPerson
{
};
```

the inherited members become:

| Base Class Member | In the Derived Class |
|---|---|
| `public` | `protected` |
| `protected` | `protected` |
| `private` | Not directly accessible |

So `public` no longer stays `public`.

It becomes `protected`.

`protected` stays `protected`.

---

## 📌 What Does Protected Inheritance Mean?

If the `Base Class` has a `public` member and we inherit it using `protected`, that member is no longer directly available from outside through an `Object`.

But it remains available inside the `Derived Class`, and classes that later inherit from that `Derived Class` can access it as `protected`.

So `protected Inheritance` can be used when we want inherited members to stay inside the inheritance chain instead of exposing them as `public` to outside users.

---

## ⚙️ Private Inheritance

When we write:

```cpp
class clsEmployee : private clsPerson
{
};
```

the inherited members become:

| Base Class Member | In the Derived Class |
|---|---|
| `public` | `private` |
| `protected` | `private` |
| `private` | Not directly accessible |

So `public` and `protected` become `private` in the `Derived Class`.

---

## 📌 What Does Private Inheritance Mean?

With `private Inheritance`, the `Derived Class` can use the inherited members inside itself, but those members are not kept available from outside.

Also, a class that later inherits from this `Derived Class` does not receive these members as `public` or `protected`.

The `Derived Class` can use the inherited code internally, but it does not expose those inherited members to the next level or outside code.

---

## 📌 What Happens in Multilevel Inheritance?

We can have more than one level:

`Base → Derived → Derived2`

The `Visibility Mode` used at each level affects the next level.

For example, with:

`public` inheritance:

`public → public`

and:

`protected → protected`

With:

`protected` inheritance:

`public → protected`

and:

`protected → protected`

With:

`private` inheritance:

`public → private`

and:

`protected → private`

---

## 💻 Example: Inheritance Levels

```cpp
class Base
{
public:
    int PublicMember;

protected:
    int ProtectedMember;

private:
    int PrivateMember;
};

class Derived : public Base
{
};

class Derived2 : public Derived
{
};
```

With `public inheritance`, `PublicMember` stays `public`, and `ProtectedMember` stays `protected`.

`PrivateMember` does not become available to the `Derived Class`.

---

## 📌 Access Specifier vs Visibility Mode

An `Access Specifier` is written **inside the Class**, such as:

`private`, `protected`, and `public`.

A `Visibility Mode` is written **in the inheritance syntax**, such as:

`public`, `protected`, and `private`.

For example:

```cpp
class clsEmployee : public clsPerson
{
};
```

The `public` here is the inheritance `Visibility Mode`.

But when we write inside a `Class`:

```cpp
class clsPerson
{
protected:
    int Var2;
};
```

`protected` here is an `Access Specifier`.

---

## 📚 Terminology

| Term | Meaning |
|---|---|
| Visibility Mode | Controls the visibility level of inherited members |
| Public Inheritance | `public` stays `public` and `protected` stays `protected` |
| Protected Inheritance | `public` becomes `protected` and `protected` stays `protected` |
| Private Inheritance | `public` and `protected` become `private` |
| Access Specifier | A specifier used inside the `Class` to control access |
| Multilevel Inheritance | Inheritance through more than one level |

---

## ⚠️ Notes

- A `private` member in the `Base Class` does not become available to the `Derived Class` because of the `Visibility Mode`.
- With `public inheritance`:
  - `public` stays `public`.
  - `protected` stays `protected`.
- With `protected inheritance`:
  - `public` becomes `protected`.
  - `protected` stays `protected`.
- With `private inheritance`:
  - `public` becomes `private`.
  - `protected` becomes `private`.
- The `Visibility Mode` also affects a class that later inherits from the `Derived Class`.
- `Visibility Modes` can control how much inherited code is exposed.

---

## 💡 Key Idea

`Visibility Mode` controls what happens to `public` and `protected` members when we inherit a `Class`.

Remember it like this:

`public inheritance`  
`public → public`  
`protected → protected`

`protected inheritance`  
`public → protected`  
`protected → protected`

`private inheritance`  
`public → private`  
`protected → private`

`private` members in the `Base Class` are not directly available to the `Derived Class`.

---

## 🔑 Summary

- `Visibility Mode` controls the visibility of inherited members.
- The modes are `public`, `protected`, and `private`.
- `public inheritance` keeps `public` and `protected` unchanged.
- `protected inheritance` changes `public` to `protected`.
- `private inheritance` changes `public` and `protected` to `private`.
- `private` members of the `Base Class` do not become available to the `Derived Class`.
- In `Multilevel Inheritance`, the inheritance mode affects the next level.
