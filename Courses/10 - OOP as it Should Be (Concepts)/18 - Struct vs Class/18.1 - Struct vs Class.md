## 📝 مقدمة

في C++ يوجد تشابه كبير بين `struct` و`class`. ويعود ذلك إلى أن `struct` كانت موجودة أصلًا في لغة C، ثم تم تطوير `class` في C++ لدعم مفاهيم **Object Oriented Programming**.

الفرق بينهما بسيط في الشكل، لكن لكل واحد منهما استخدام مناسب حسب الهدف من الكود.

---

## 🧠 لمحة سريعة

لغة C++ هي امتداد للغة C، وتدعم **Object Oriented Programming**، بينما لغة C لا تدعمها.

كانت `struct` موجودة في C بهدف تجميع البيانات معًا في نوع بيانات واحد. وعند تطوير C++، تم بناء `class` على أساس `struct` وإضافة إمكانيات مرتبطة بالـOOP.

---

## 🎯 التعريف: Struct وClass

> **Struct**
>
> نوع بيانات استُخدم أساسًا لتجميع البيانات معًا، وهو موجود منذ لغة C.

> **Class**
>
> نوع بيانات في C++ تم تطويره على أساس `struct` ليدعم استخدامات مرتبطة بـObject Oriented Programming مثل methods وinheritance.

---

## ⚙️ الفرق في الـDefault Access

من أهم الاختلافات في C++ هو مستوى الوصول الافتراضي.

في `class` يكون الـdefault هو `private`.

أما في `struct` فيكون الـdefault هو `public`.

| `struct` | `class` |
|---|---|
| Default: `public` | Default: `private` |

لذلك عند تعريف member بدون كتابة `public` أو `private`، تختلف إمكانية الوصول الافتراضية حسب النوع المستخدم.

---

## ⚙️ الهدف الرئيسي

وفق الشرح، الهدف الرئيسي من `struct` هو **Grouping Data**، أي جمع البيانات معًا تحت نوع واحد.

أما `class` فالهدف الرئيسي منها هو استخدام إمكانيات أكبر مرتبطة بالـOOP، مثل **data abstraction** و**inheritance** ووجود methods.

| `struct` | `class` |
|---|---|
| تستخدم أساسًا لتجميع البيانات | تستخدم لـObject Oriented Programming |
| مناسبة عندما يكون الهدف هو Grouping Data | مناسبة عند وجود methods أو استخدامات OOP مثل inheritance |

---

## ⚙️ الـMemory Type

يذكر الشرح أن `struct` تعتبر **Value Type** وتخزن في **Stack**، بينما `class` تعتبر **Reference Type** وتخزن في **Heap**.

وبناءً على هذا العرض، يتم ربط `struct` بالبيانات الصغيرة، بينما يتم استخدام `class` عندما تكون الحاجة إلى إمكانيات OOP أكبر.

> **ملاحظة على المصطلح**
>
> هذه المقارنة هي كما قُدمت في المادة التعليمية، ولذلك يجب حفظها ضمن سياق هذا الشرح.

---

## ⚙️ Constructors

بحسب الشرح، `struct` تدعم **Parameterized Constructors**، بينما `class` تدعم أنواع الـconstructors المختلفة.

كما يشير الشرح إلى أن `struct` في أصلها كانت موجهة لتجميع البيانات، بينما `class` هي الخيار المستخدم عندما نحتاج إلى methods أو إمكانيات OOP.

---

## 💡 متى نستخدم Struct ومتى نستخدم Class؟

القاعدة العملية في الشرح بسيطة:

- إذا كان الهدف هو **Grouping Data**، استخدم `struct`.
- إذا كان لديك **function أو method**، استخدم `class`.
- إذا كنت تحتاج إلى `inheritance` أو إمكانيات مرتبطة بـObject Oriented Programming، استخدم `class`.

كما يذكر الشرح أن ليس كل لغات البرمجة تدعم `struct`، لذلك وجود methods يجعل `class` اختيارًا عمليًا ضمن هذه القاعدة.

---

## 📌 مقارنة سريعة

| النقطة | `struct` | `class` |
|---|---|---|
| الكلمة المفتاحية | `struct` | `class` |
| الـDefault Access | `public` | `private` |
| الهدف الأساسي | Grouping Data | Data Abstraction وOOP |
| Methods | لا تستخدم عندما يكون الهدف مجرد تجميع البيانات | تستخدم عند وجود methods |
| Inheritance | لا يُستخدم وفق قاعدة الشرح | تستخدم |
| Constructors | Parameterized Constructors وفق الشرح | جميع أنواع الـconstructors وفق الشرح |
| المقارنة في الذاكرة | Value Type / Stack وفق الشرح | Reference Type / Heap وفق الشرح |

---

## ⚠️ ملاحظات

- `struct` و`class` متشابهان جدًا في C++ لأن `class` بُنيت على `struct` الموجودة في C.
- الاختلاف الواضح في الـdefault access هو أن `struct` تبدأ بـ`public`، بينما `class` تبدأ بـ`private`.
- وفق قاعدة الشرح، استخدم `struct` عندما يكون المطلوب تجميع البيانات، واستخدم `class` عند وجود methods أو احتياجات OOP.
- لا تخلط بين الغرض من النوعين عند تصميم الكود.

---

## 💡 الفكرة الأساسية

`struct` و`class` متشابهان في C++، لكن الشرح يضع قاعدة عملية بسيطة:

**Grouping Data → `struct`**

**Methods / OOP → `class`**

وأهم فرق مباشر يجب تذكره هو الـdefault access: `public` في `struct` و`private` في `class`.

---

## 🔑 الملخص

- `struct` كانت موجودة في C لتجميع البيانات.
- `class` طُورت في C++ على أساس `struct` لدعم OOP.
- `struct` تبدأ افتراضيًا بـ`public`.
- `class` تبدأ افتراضيًا بـ`private`.
- `struct` مناسبة لـGrouping Data وفق الشرح.
- `class` مناسبة عند وجود methods أو inheritance أو استخدامات OOP.
- المادة تذكر أن `struct` تدعم Parameterized Constructors، بينما `class` تدعم أنواع الـconstructors المختلفة.
- مقارنة Stack وHeap في هذه الوحدة تُحفظ كما وردت في الشرح.

## 📝 Introduction

In C++, there is a big similarity between `struct` and `class`. This is because `struct` already existed in C, and then `class` was developed in C++ to support **Object Oriented Programming**.

The difference between them is simple, but each one has a suitable use depending on the purpose of the code.

---

## 🧠 Quick Recap

C++ is an extension of C, and it supports **Object Oriented Programming**, while C does not support it.

`struct` already existed in C to group data together in one data type. When C++ was developed, `class` was built based on `struct` and extra OOP-related abilities were added.

---

## 🎯 Definition: Struct and Class

> **Struct**
>
> A data type that was mainly used to group data together, and it already existed in C.

> **Class**
>
> A data type in C++ developed based on `struct` to support Object Oriented Programming uses such as methods and inheritance.

---

## ⚙️ Default Access Difference

One important difference in C++ is the default access level.

In a `class`, the default is `private`.

In a `struct`, the default is `public`.

| `struct` | `class` |
|---|---|
| Default: `public` | Default: `private` |

So, when a member is declared without writing `public` or `private`, the default access depends on the type being used.

---

## ⚙️ Main Purpose

According to the explanation, the main purpose of `struct` is **Grouping Data**, which means putting data together under one type.

The main purpose of `class` is to use more OOP-related abilities such as **data abstraction**, **inheritance**, and methods.

| `struct` | `class` |
|---|---|
| Mainly used for grouping data | Used for Object Oriented Programming |
| Suitable when the goal is Grouping Data | Suitable when there are methods or OOP uses such as inheritance |

---

## ⚙️ Memory Type

The explanation says that `struct` is a **Value Type** stored in the **Stack**, while `class` is a **Reference Type** stored in the **Heap**.

Based on this explanation, `struct` is connected with small data, while `class` is used when more OOP features are needed.

> **Note about the terminology**
>
> This comparison is kept as it was presented in the course material, so it should be remembered in the context of this lesson.

---

## ⚙️ Constructors

According to the explanation, `struct` supports **Parameterized Constructors**, while `class` supports different constructor types.

The explanation also says that `struct` was originally used for grouping data, while `class` is the choice when we need methods or OOP features.

---

## 💡 When to Use Struct and When to Use Class?

The practical rule in the explanation is simple:

- If the goal is **Grouping Data**, use `struct`.
- If you have a **function or method**, use `class`.
- If you need `inheritance` or other Object Oriented Programming features, use `class`.

The explanation also says that not all programming languages support `struct`, so having methods makes `class` a practical choice under this rule.

---

## 📌 Quick Comparison

| Point | `struct` | `class` |
|---|---|---|
| Keyword | `struct` | `class` |
| Default Access | `public` | `private` |
| Main Purpose | Grouping Data | Data Abstraction and OOP |
| Methods | Not used when the goal is only grouping data | Used when there are methods |
| Inheritance | Not used according to this course rule | Used |
| Constructors | Parameterized Constructors according to the explanation | Different constructor types according to the explanation |
| Memory comparison | Value Type / Stack according to the explanation | Reference Type / Heap according to the explanation |

---

## ⚠️ Notes

- `struct` and `class` are very similar in C++ because `class` was built based on `struct` from C.
- The clear default access difference is `public` for `struct` and `private` for `class`.
- According to the course rule, use `struct` for grouping data and `class` when there are methods or OOP needs.
- Do not mix the purpose of the two types when designing the code.

---

## 💡 Key Idea

`struct` and `class` are very similar in C++, but the lesson gives a simple practical rule:

**Grouping Data → `struct`**

**Methods / OOP → `class`**

The main direct difference to remember is the default access: `public` in `struct` and `private` in `class`.

---

## 🔑 Summary

- `struct` existed in C for grouping data.
- `class` was developed in C++ based on `struct` to support OOP.
- `struct` has default `public` access.
- `class` has default `private` access.
- `struct` is suitable for Grouping Data according to the explanation.
- `class` is suitable when there are methods, inheritance, or OOP uses.
- The material says that `struct` supports Parameterized Constructors, while `class` supports different constructor types.
- The Stack and Heap comparison in this lesson should be remembered as presented in the course.
