# What is ‘this’ pointer

<a id="arabic"></a>
[English ↙](#english)

<div dir="rtl" style="text-align:right;font-family:'Arial',sans-serif;">

## 📝 مقدمة

الكلمة المحجوزة `this` في C++ تمثل مؤشراً إلى الكائن الحالي الذي نعمل عليه داخل الفئة.

يستخدم المترجم `this` ضمنياً عند الوصول إلى أعضاء الفئة من داخل دالة عضو، لذلك يمكن كتابة اسم العضو مباشرةً في كثير من الحالات.

---

## 🧠 مراجعة سريعة

الفئة `clsEmployee` تحتوي على أعضاء عامة: `ID` و`Name` و`Salary`، وعلى constructor يستقبل القيم نفسها، إضافة إلى الدوال `Func1` و`Func2` و`Print`.

في `main` يتم إنشاء `Employee1` بالقيم `101` و`"Ali"` و`5000`، ثم يتم استدعاء `Print()` و`Func2()`.

---

## 🎯 تعريف: `this` Pointer

> **`this` Pointer (مؤشر `this`)**
>
> هو مؤشر يشير إلى الكائن الحالي الذي يتم تنفيذ دالة عضو عليه.

عند إنشاء كائن من `clsEmployee`، يشير `this` داخل دوال العضو إلى ذلك الكائن الحالي.

---

## ⚙️ الوصول إلى أعضاء الفئة باستخدام `this`

داخل `()Print` يمكن الوصول إلى `ID` و`Name` و`Salary` مباشرةً:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
void Print()
{
    cout << ID << "  " << Name << "  " << Salary << endl;
    // cout << this->ID << "  " << this->Name << "  " << this->Salary << endl;
}
```
</div>

الطريقتان تعطيان النتيجة نفسها في هذا المثال. المترجم يتعامل ضمنياً مع أعضاء الفئة كما لو تم الوصول إليها من خلال `this`.

وبما أن `this` هو Pointer، فإن الوصول إلى العضو يكون باستخدام `<-`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
this->ID
this->Name
this->Salary
```
</div>

`this` يشير إلى الكائن الحالي، ومن خلاله يمكن الوصول إلى أعضاء الفئة المذكورين هنا.

---

## 💻 مثال: استخدام `this` مع الأسماء المتشابهة

عندما تكون أسماء parameters في الـ constructor هي نفسها أسماء أعضاء الفئة، يمكن استخدام `this` لتمييزها:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
clsEmployee (int ID, string Name, float Salary)
{
   this->ID = ID;
   this->Name = Name;
   this->Salary = Salary;
}
```
</div>

في `this->ID = ID`، العضو `ID` الذي يسبق `<-` هو عضو الكائن الحالي، بينما `ID` بعد علامة `=` هو parameter الخاص بالـ constructor.

والفكرة نفسها تنطبق على `Name` و`Salary`.

---

## ⚙️ تمرير الكائن الحالي إلى دالة أخرى

يمكن استخدام `this` أيضاً للوصول إلى الكائن الحالي وتمريره إلى دالة أخرى.

في المثال، `Func1` هي دالة `static` وتستقبل كائناً من نوع `clsEmployee`، ثم تستدعي `()Print` على هذا الكائن:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
static void Func1(clsEmployee Employee)
{
    Employee.Print();
}
```
</div>

أما `Func2` فتستدعي `Func1` وترسل إليها الكائن الحالي من خلال `this*`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
void Func2()
{
    Func1( *this );
}
```
</div>

`this` هو مؤشر إلى الكائن الحالي، ولذلك `this*` يمثل الكائن نفسه. في هذا المثال يتم تمرير الكائن الحالي إلى `Func1`.

---

## 💻 مثال: `()Employee1.Func2`

عند تنفيذ:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
clsEmployee Employee1 (101, "Ali", 5000); 
Employee1.Print();
Employee1.Func2();
```
</div>

يقوم `()Func2` بتمرير الكائن الحالي إلى `Func1` باستخدام `this*`، ثم تقوم `Func1` باستدعاء `()Employee.Print`.

لهذا تظهر بيانات `Employee1` عند تنفيذ `()Func2` أيضاً.

---

## 📌 `this` و`Friend Function`

أعضاء الفئة يمكن الوصول إليها من داخل دوال العضو باستخدام `this`، أما `Friend Function` فليست دالة عضو في الفئة، ولذلك لا تُعامل كدالة عضو عند الحديث عن `this`.


---

## ⚠️ ملاحظات

- `this` يشير إلى الكائن الحالي داخل دالة العضو.
- لأن `this` مؤشّر، يتم الوصول إلى أعضاء الكائن من خلال `<-`.
- يمكن كتابة أعضاء الفئة مباشرةً في كثير من الحالات لأن المترجم يتعامل معها ضمنياً من خلال `this`.
- عند تشابه اسم parameter مع اسم عضو في الفئة، يصبح استخدام `<-this` مفيداً للتمييز بينهما.
- `this` يمكن استخدامه هنا لإرسال الكائن الحالي إلى `Func1` من خلال `this*`.

---

## 💡 الفكرة الأساسية
                                                                                                                    
`this` هو مؤشر إلى الكائن الحالي. غالباً لا تحتاج إلى كتابته عند الوصول إلى أعضاء الفئة من داخل دوال العضو، لكنك تحتاجه بشكل واضح عندما تريد تمييز عضو الفئة عن parameter يحمل الاسم نفسه، أو عندما تريد الوصول إلى الكائن الحالي وتمريره إلى دالة أخرى باستخدام `this*`.

---

## 🔑 ملخص

`this` في C++ يشير إلى الكائن الحالي. داخل `clsEmployee` يمكنه الوصول إلى `ID` و`Name` و`Salary`، ويُستخدم في constructor لتمييز أعضاء الفئة عن parameters ذات الأسماء نفسها. وفي `Func2` يتم استخدام `this*` لتمرير الكائن الحالي إلى `Func1`.

## 📝 Introduction

The keyword `this` in C++ represents a pointer to the current object that we are working on inside the class.

The compiler uses `this` implicitly when accessing class members from a member function, so we can write the member name directly in many cases.

---

## 🧠 Quick Recap

The class `clsEmployee` has public members `ID`, `Name`, and `Salary`. It also has a constructor that receives the same values, and the functions `Func1`, `Func2`, and `Print`.

In `main`, `Employee1` is created with `101`, `"Ali"`, and `5000`, then `Print()` and `Func2()` are called.

---

## 🎯 Definition: `this` Pointer

> **`this` Pointer**
>
> It is a pointer that points to the current object on which a member function is being executed.

When an object of `clsEmployee` is created, `this` inside member functions points to that current object.

---

## ⚙️ Accessing Class Members With `this`

Inside `Print()`, we can access `ID`, `Name`, and `Salary` directly:

```cpp
void Print()
{
    cout << ID << "  " << Name << "  " << Salary << endl;
    // cout << this->ID << "  " << this->Name << "  " << this->Salary << endl;
}
```

Both ways give the same result in this example. The compiler handles the class members implicitly as access through `this`.

Because `this` is a pointer, member access with it uses `->`:

```cpp
this->ID
this->Name
this->Salary
```

`this` points to the current object, and through it we can access the class members shown here.

---

## 💻 Example: Using `this` With Same Names

When constructor parameters have the same names as class members, `this` can be used to distinguish them:

```cpp
clsEmployee (int ID, string Name, float Salary)
{
   this->ID = ID;
   this->Name = Name;
   this->Salary = Salary;
}
```

In `this->ID = ID`, the `ID` before `=` is the member of the current object, while the `ID` after `=` is the constructor parameter.

The same idea applies to `Name` and `Salary`.

---

## ⚙️ Passing the Current Object to Another Function

`this` can also be used to access the current object and pass it to another function.

In the example, `Func1` is a `static` function. It receives a `clsEmployee` object and then calls `Print()` on that object:

```cpp
static void Func1(clsEmployee Employee)
{
    Employee.Print();
}
```

`Func2` calls `Func1` and sends the current object through `*this`:

```cpp
void Func2()
{
    Func1( *this );
}
```

`this` is a pointer to the current object, so `*this` represents the object itself. In this example, the current object is passed to `Func1`.

---

## 💻 Example: `Employee1.Func2()`

When we run:

```cpp
clsEmployee Employee1 (101, "Ali", 5000); 
Employee1.Print();
Employee1.Func2();
```

`Func2()` passes the current object to `Func1` using `*this`, and then `Func1` calls `Employee.Print()`.

So the data of `Employee1` is also printed when `Func2()` runs.

---

## 📌 `this` and `Friend Function`

Class members can be accessed from member functions using `this`. A `Friend Function` is not a member function of the class, so it is not treated as a member function when talking about `this`.

---


## ⚠️ Notes

- `this` points to the current object inside a member function.
- Because `this` is a pointer, member access through it uses `->`.
- We can write class members directly in many cases because the compiler handles them implicitly through `this`.
- When a parameter has the same name as a class member, `this->` helps distinguish them.
- `this` can be used here to send the current object to `Func1` through `*this`.

---

## 💡 Key Idea

`this` is a pointer to the current object. You usually do not need to write it when accessing class members from a member function, but it is useful when you need to distinguish a class member from a parameter with the same name, or when you need to access the current object and pass it to another function using `*this`.

---

## 🔑 Summary

`this` in C++ points to the current object. Inside `clsEmployee`, it can access `ID`, `Name`, and `Salary`, and it is used in the constructor to distinguish class members from parameters with the same names. In `Func2`, `*this` is used to pass the current object to `Func1`.
