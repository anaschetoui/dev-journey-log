# Objects and Dynamic Array

## 📝 مقدمة

يمكن إنشاء مصفوفة ديناميكية من الكائنات، وليس فقط من الأنواع البسيطة. في هذا المثال يتم إنشاء مصفوفة ديناميكية من نوع `clsA` باستخدام الكلمة المفتاحية `new`، ثم يتم إعطاء قيمة لكل كائن، وبعد ذلك تتم طباعة محتويات جميع الكائنات.

---

## 🧠 مراجعة سريعة

الفئة `clsA` تحتوي على متغيّر اسمه `x` ودالة عضو اسمها `()Print`. كما تحتوي على **Dummy Constructor** بدون معاملات، بالإضافة إلى **Parameterized Constructor** يستقبل قيمة ويضعها في `x`.

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsA
{
public:

    // dummy constructor
    clsA() {}

    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }
};
```
</div>

---

## 🎯 التعريف: Dynamic Array of Objects

> **Dynamic Array of Objects**
>
> هي مصفوفة يتم حجزها في الذاكرة بشكل ديناميكي باستخدام `new`، ويمكن أن تحتوي على كائنات من الفئة نفسها.

في المثال يتم إنشاء مصفوفة ديناميكية من خمسة كائنات من `clsA`.

---

## ⚙️ إنشاء المصفوفة الديناميكية

يتم تحديد عدد الكائنات أولًا:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
short NumberOfObjects = 5;
```
</div>

ثم يتم حجز مصفوفة ديناميكية من نوع `clsA` باستخدام `new`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
clsA * arrA = new clsA[NumberOfObjects];
```
</div>

المتغيّر `arrA` يشير إلى بداية المصفوفة الديناميكية، وحجمها هو `NumberOfObjects`.

---

## ⚙️ تهيئة الكائنات داخل المصفوفة

بعد إنشاء المصفوفة، يتم المرور على كل عنصر باستخدام `for`، ويتم إنشاء كائن من `clsA` باستخدام الـ parameterized constructor:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
for (int i = 0; i < NumberOfObjects; i++) {
    arrA[i] = clsA(i);
}
```
</div>

في كل دورة، يتم إنشاء `clsA(i)` ثم إسناده إلى العنصر `arrA[i]`.

لذلك تكون قيم `x` في الكائنات حسب قيم `i` المستخدمة في الحلقة.

---

## ⚙️ طباعة محتويات المصفوفة

بعد تهيئة جميع العناصر، يتم المرور على المصفوفة مرة أخرى واستدعاء `()Print` لكل كائن:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
for (int i = 0; i < NumberOfObjects; i++) {
    arrA[i].Print();
}
```
</div>

كل عنصر في المصفوفة هو كائن من `clsA`، لذلك يمكن استدعاء دالة العضو `()Print` باستخدام `()arrA[i].Print`.

---

## 💻 مثال

الكود الكامل:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud
#include<iostream>
#include<vector>

using namespace std;

class clsA
{
public:

    // dummy constructor
    clsA() {}

    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x <<endl;
    }

};


int main() 

{
    short NumberOfObjects = 5;

    // allocating dynamic array
    // of Size NumberOfObjects using new keyword

    clsA * arrA = new clsA[NumberOfObjects];

    // calling constructor
    // for each index of array
    for (int i = 0; i < NumberOfObjects; i++) {
        arrA[i] = clsA(i);
    }

    // printing contents of array
    for (int i = 0; i < NumberOfObjects; i++) {
        arrA[i].Print();
    }

    return 0;

    
    system("pause>0");

}
```
</div>

أهم خطوات المثال:

1. `NumberOfObjects` يحدد عدد الكائنات، وقيمته `5`.
2. `new clsA[NumberOfObjects]` ينشئ المصفوفة الديناميكية.
3. الحلقة الأولى تعطي قيمة لكل عنصر عن طريق `clsA(i)`.
4. الحلقة الثانية تستدعي `Print()` لكل كائن.

---

## 📌 الفرق بين المصفوفة العادية والمصفوفة الديناميكية في هذا المثال

| المصفوفة العادية | المصفوفة الديناميكية |
|---|---|
| لا يتم حجزها باستخدام `new` في المثال | يتم حجزها باستخدام `new` |
| المثال هنا لا يستخدمها | المثال هنا يستخدم `clsA * arrA` |
| عدد العناصر يكون محددًا عند تعريفها | الحجم هنا يعتمد على `NumberOfObjects` عند الحجز |

---

## ⚠️ ملاحظة مهمة

الفئة `clsA` تحتوي على **Dummy Constructor**:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
clsA() {}
```
</div>

كما تحتوي على الـ **Parameterized Constructor**:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
clsA(int value)
{
    x = value;
}
```
</div>

في المثال، المصفوفة يتم إنشاؤها أولًا باستخدام:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
new clsA[NumberOfObjects]
```
</div>

ثم يتم تعيين كل عنصر باستخدام `clsA(i)` في الحلقة الأولى.

كما أن `return 0;` موجود قبل `system("pause>0");` في الكود المقدم، لذلك السطر الموجود بعد `return` لن يتم الوصول إليه أثناء التنفيذ.

---

## 💡 الفكرة الأساسية

يمكن إنشاء مصفوفة ديناميكية تحتوي على كائنات باستخدام `new` مع نوع الفئة.
بعد ذلك يمكن التعامل مع كل عنصر باستخدام الفهرس، مثل `arrA[i]`، واستدعاء دوال العضو عليه مثل `arrA[i].Print()`.

---

## 🔑 الملخص

- يمكن إنشاء **Dynamic Array** من الكائنات.
- يتم استخدام `new` لحجز المصفوفة الديناميكية.
- `clsA * arrA = new clsA[NumberOfObjects];` ينشئ مصفوفة ديناميكية من `clsA`.
- الحلقة الأولى تهيئ كل عنصر باستخدام `clsA(i)`.
- `arrA[i].Print()` تستدعي `Print()` للكائن الموجود في الفهرس `i`.
- المثال يستخدم **Dummy Constructor** و**Parameterized Constructor**.

## 📝 Introduction

A dynamic array can contain objects, not only simple data types. In this example, a dynamic array of `clsA` objects is created using the `new` keyword. Then each object is given a value, and the contents of all objects are printed.

---

## 🧠 Quick Recap

The class `clsA` contains a variable named `x` and a member function named `Print()`. It also has a **Dummy Constructor** without parameters and a **Parameterized Constructor** that receives a value and stores it in `x`.

```cpp
class clsA
{
public:

    // dummy constructor
    clsA() {}

    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }
};
```

---

## 🎯 Definition: Dynamic Array of Objects

> **Dynamic Array of Objects**
>
> An array that is allocated dynamically using `new` and can contain objects of the same class.

In this example, a dynamic array of five `clsA` objects is created.

---

## ⚙️ Creating the Dynamic Array

First, the number of objects is defined:

```cpp
short NumberOfObjects = 5;
```

Then a dynamic array of `clsA` is allocated using `new`:

```cpp
clsA * arrA = new clsA[NumberOfObjects];
```

The variable `arrA` points to the beginning of the dynamic array, and its size is `NumberOfObjects`.

---

## ⚙️ Initializing the Objects in the Array

After creating the array, a `for` loop goes through each element and creates a `clsA` object using the parameterized constructor:

```cpp
for (int i = 0; i < NumberOfObjects; i++) {
    arrA[i] = clsA(i);
}
```

In each loop, `clsA(i)` creates an object and assigns it to `arrA[i]`.

So, the `x` values of the objects follow the values of `i` used in the loop.

---

## ⚙️ Printing the Array Contents

After all elements are initialized, another loop goes through the array and calls `Print()` for each object:

```cpp
for (int i = 0; i < NumberOfObjects; i++) {
    arrA[i].Print();
}
```

Each element in the array is a `clsA` object, so the member function `Print()` can be called with `arrA[i].Print()`.

---

## 💻 Example

The complete code:

```cpp
//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud
#include<iostream>
#include<vector>

using namespace std;

class clsA
{
public:

    // dummy constructor
    clsA() {}

    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x <<endl;
    }

};


int main() 

{
    short NumberOfObjects = 5;

    // allocating dynamic array
    // of Size NumberOfObjects using new keyword

    clsA * arrA = new clsA[NumberOfObjects];

    // calling constructor
    // for each index of array
    for (int i = 0; i < NumberOfObjects; i++) {
        arrA[i] = clsA(i);
    }

    // printing contents of array
    for (int i = 0; i < NumberOfObjects; i++) {
        arrA[i].Print();
    }

    return 0;

    
    system("pause>0");

}
```

Important steps in the example:

1. `NumberOfObjects` defines the number of objects, and its value is `5`.
2. `new clsA[NumberOfObjects]` creates the dynamic array.
3. The first loop gives a value to each element using `clsA(i)`.
4. The second loop calls `Print()` for each object.

---

## 📌 Difference Between a Normal Array and a Dynamic Array in This Example

| Normal Array | Dynamic Array |
|---|---|
| It is not allocated using `new` in the example | It is allocated using `new` |
| It is not used here | It uses `clsA * arrA` |
| The number of elements is defined when the array is declared | The size here depends on `NumberOfObjects` when the array is allocated |

---

## ⚠️ Important Note

The class `clsA` has a **Dummy Constructor**:

```cpp
clsA() {}
```

It also has the **Parameterized Constructor**:

```cpp
clsA(int value)
{
    x = value;
}
```

In the example, the array is first created with:

```cpp
new clsA[NumberOfObjects]
```

Then each element is assigned using `clsA(i)` in the first loop.

Also, `return 0;` appears before `system("pause>0");` in the provided code, so the line after `return` is not reached during execution.

---

## 💡 Key Idea

A dynamic array of objects can be created using `new` with the class type.
Then each element can be accessed using its index, such as `arrA[i]`, and member functions can be called on it, such as `arrA[i].Print()`.

---

## 🔑 Summary

- A **Dynamic Array** can contain objects.
- `new` is used to allocate the dynamic array.
- `clsA * arrA = new clsA[NumberOfObjects];` creates a dynamic array of `clsA` objects.
- The first loop initializes each element using `clsA(i)`.
- `arrA[i].Print()` calls `Print()` for the object at index `i`.
- The example uses a **Dummy Constructor** and a **Parameterized Constructor**.
