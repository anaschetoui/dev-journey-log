# Objects with Parameterized Constructor and Array

## 📝 مقدمة

يمكن إنشاء مصفوفة من الكائنات التي تحتوي على **Parameterized Constructor**، ثم تهيئة كل عنصر باستخدام استدعاء الـ constructor المناسب عند تعريف المصفوفة.

---

## 🧠 مراجعة سريعة

الفئة `clsA` تحتوي على:

- متغيّر عام `x` من النوع `int`.
- **Parameterized Constructor** يستقبل `value` ويضعه في `x`.
- دالة عضو `Print()` لعرض قيمة `x`.

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

class clsA
{
public:

    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};
```

</div>

---

## 🎯 التعريف: Objects with Parameterized Constructor and Array

> **Objects with Parameterized Constructor and Array**
>
> هي تهيئة مصفوفة تحتوي على كائنات، بحيث يتم إنشاء كل كائن باستخدام **Parameterized Constructor** كعنصر من عناصر المصفوفة.

---

## ⚙️ تهيئة مصفوفة من الكائنات

يمكن تعريف مصفوفة من الكائنات وتهيئة عناصرها باستخدام استدعاءات الـ constructor:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

clsA obj[] = { clsA(10), clsA(20), clsA(30) };
```

</div>

هنا تم إنشاء ثلاثة كائنات من `clsA` داخل المصفوفة `obj`.

كل كائن يتم إنشاؤه باستخدام الـ constructor:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

clsA(10)
clsA(20)
clsA(30)
```

</div>

وبالتالي تكون قيم `x` للكائنات هي `10` و`20` و`30`.

---

## ⚙️ الوصول إلى عناصر المصفوفة

يمكن الوصول إلى كل كائن باستخدام الفهرس `i`، ثم استدعاء `()Print`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

obj[i].Print();
```

</div>

حيث `obj[i]` يمثل الكائن الموجود في العنصر رقم `i`.

---

## 💻 مثال

الكود الكامل:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud
#include<iostream>
#include<vector>

using namespace std;

class clsA
{
public:

    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};


int main() 

{

    // Initializing 3 array Objects with function calls of
    // parameterized constructor as elements of that array
    clsA obj[] = { clsA(10), clsA(20), clsA(30) };

    // using print method for each of three elements.
    for (int i = 0; i < 3; i++) {
        obj[i].Print();
    }

    return 0;


    system("pause>0");

}
```

</div>

السطر:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

clsA obj[] = { clsA(10), clsA(20), clsA(30) };
```

</div>

يقوم بإنشاء مصفوفة من ثلاثة كائنات.

ثم تستخدم الحلقة:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

for (int i = 0; i < 3; i++)
```

</div>

للمرور على العناصر الثلاثة.

وفي كل مرة يتم استدعاء:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

obj[i].Print();
```

</div>

لعرض قيمة `x` الخاصة بالكائن الحالي.

---

## 📌 طريقة إنشاء العناصر

في هذا المثال، يتم إنشاء كل عنصر من عناصر المصفوفة باستخدام **Parameterized Constructor**:

| العنصر | constructor | قيمة `x` |
|---|---|---:|
| `obj[0]` | `clsA(10)` | `10` |
| `obj[1]` | `clsA(20)` | `20` |
| `obj[2]` | `clsA(30)` | `30` |

---

## ⚠️ ملاحظة مهمة

المصفوفة هنا لا تحتوي على قيم `int` مباشرة، بل تحتوي على **كائنات من `clsA`**.

لذلك يتم الوصول إلى كل عنصر ككائن:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp

obj[i].Print();
```

</div>

وليس كقيمة `x` مباشرة.

---

## 💡 الفكرة الأساسية

يمكن إنشاء مصفوفة من الكائنات وتهيئة عناصرها باستخدام **Parameterized Constructor**.

في المثال، تم إنشاء ثلاثة كائنات بالقيم `10` و`20` و`30`، ثم تم استخدام `()Print` لعرض قيمة `x` لكل كائن.

---

## 🔑 الملخص

- يمكن أن تحتوي المصفوفة على كائنات من فئة مثل `clsA`.
- يمكن تهيئة الكائنات عند تعريف المصفوفة.
- يتم استخدام **Parameterized Constructor** لكل عنصر.
- المثال ينشئ ثلاثة كائنات: `clsA(10)` و`clsA(20)` و`clsA(30)`.
- يمكن الوصول إلى كل كائن باستخدام الفهرس مثل `obj[i]`.
- يمكن استدعاء `()Print` لكل كائن باستخدام `()obj[i].Print`.

## 📝 Introduction

We can create an array of objects that has a **Parameterized Constructor**, then initialize each element by calling the constructor when defining the array.

---

## 🧠 Quick Recap

The class `clsA` contains:

- A public variable `x` of type `int`.
- A **Parameterized Constructor** that receives `value` and assigns it to `x`.
- A member function `Print()` to display the value of `x`.

```cpp
class clsA
{
public:

    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};
```

---

## 🎯 Definition: Objects with Parameterized Constructor and Array

> **Objects with Parameterized Constructor and Array**
>
> Creating an array that contains objects, where each object is created using a **Parameterized Constructor** as an element of the array.

---

## ⚙️ Initializing an Array of Objects

We can define an array of objects and initialize its elements by calling the constructor:

```cpp
clsA obj[] = { clsA(10), clsA(20), clsA(30) };
```

Here, three objects of `clsA` are created inside the `obj` array.

Each object is created using the constructor:

```cpp
clsA(10)
clsA(20)
clsA(30)
```

So, the `x` values of the objects are `10`, `20`, and `30`.

---

## ⚙️ Accessing Array Elements

We can access each object using the index `i`, then call `Print()`:

```cpp
obj[i].Print();
```

Here, `obj[i]` represents the object at index `i`.

---

## 💻 Example

The complete code:

```cpp
//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud
#include<iostream>
#include<vector>

using namespace std;

class clsA
{
public:

    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};


int main() 

{

    // Initializing 3 array Objects with function calls of
    // parameterized constructor as elements of that array
    clsA obj[] = { clsA(10), clsA(20), clsA(30) };

    // using print method for each of three elements.
    for (int i = 0; i < 3; i++) {
        obj[i].Print();
    }

    return 0;


    system("pause>0");

}
```

The line:

```cpp
clsA obj[] = { clsA(10), clsA(20), clsA(30) };
```

creates an array of three objects.

Then the loop:

```cpp
for (int i = 0; i < 3; i++)
```

goes through the three elements.

Each time it calls:

```cpp
obj[i].Print();
```

to display the `x` value of the current object.

---

## 📌 How the Elements Are Created

In this example, each array element is created using the **Parameterized Constructor**:

| Element | Constructor | `x` value |
|---|---|---:|
| `obj[0]` | `clsA(10)` | `10` |
| `obj[1]` | `clsA(20)` | `20` |
| `obj[2]` | `clsA(30)` | `30` |

---

## ⚠️ Important Note

The array here does not contain `int` values directly. It contains **objects of `clsA`**.

So each element is accessed as an object:

```cpp
obj[i].Print();
```

not as the `x` value directly.

---

## 💡 Key Idea

We can create an array of objects and initialize its elements using a **Parameterized Constructor**.

In the example, three objects are created with the values `10`, `20`, and `30`, then `Print()` is used to display the `x` value of each object.

---

## 🔑 Summary

- An array can contain objects from a class such as `clsA`.
- Objects can be initialized when the array is defined.
- A **Parameterized Constructor** is used for each element.
- The example creates three objects: `clsA(10)`, `clsA(20)`, and `clsA(30)`.
- Each object can be accessed using an index such as `obj[i]`.
- `Print()` can be called for each object using `obj[i].Print()`.
