# Passing Objects to Functions (ByRef/ByVal)

<a id="arabic"></a>
[English ↙](#english)

<div dir="rtl" style="text-align:right;font-family:'Arial',sans-serif;">

## 📝 مقدمة

يمكن التعامل مع الكائنات مثل أي نوع بيانات آخر مثل `int` و`bool` و`string`. ويمكن تمرير الكائنات إلى الدوال كمعاملات بطريقتين: **بالقيمة (ByVal)** أو **بالمرجع (ByRef)**.

---

## 🧠 مراجعة سريعة

الفئة `clsA` تحتوي على متغيّر عام اسمه `x` ودالة عضو اسمها `()Print` لعرض قيمة `x`.

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsA
{

public:
    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};
```

</div>

---

## 🎯 التعريف: Passing Objects to Functions

> **Passing Objects to Functions**
>
> هو تمرير كائن من فئة معينة إلى دالة كمعامل، إما **بالقيمة (ByVal)** أو **بالمرجع (ByRef)**.

---

## ⚙️ التمرير بالقيمة (ByVal)

عند تمرير الكائن بالقيمة، يتم إرسال نسخة منه إلى الدالة. لذلك، أي تعديل على الكائن داخل الدالة لا ينعكس على الكائن الأصلي.

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
void Fun1(clsA A1)
{

    A1.x = 100;
}
```

</div>

هنا تم تمرير `A1` إلى `Fun1` **بالقيمة**.

عندما تصبح `A1.x` مساوية لـ `100` داخل `Fun1`، فإن التعديل لا يغيّر الكائن الأصلي الموجود في `main`.

---

## ⚙️ التمرير بالمرجع (ByRef)

عند تمرير الكائن بالمرجع، يتم استخدام الكائن الأصلي داخل الدالة، لذلك أي تعديل عليه ينعكس على الكائن الأصلي.

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
void Fun2(clsA &A1)
{

    A1.x = 200;
}
```

</div>

وجود `&` في `clsA &A1` يعني أن الكائن تم تمريره **بالمرجع**.

لذلك، عندما تصبح `A1.x` مساوية لـ `200` داخل `Fun2`، تتغير قيمة `x` في الكائن الأصلي أيضًا.

---

## 💻 مثال

الكود الكامل:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
#include<iostream>

using namespace std;

class clsA
{

public:
    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};


//object sent by value, any updated will not b reflected
// on the original object
void Fun1(clsA A1)
{

    A1.x = 100;
}


//object sent by reference, any updated will be reflected
// on the original object
void Fun2(clsA &A1)
{

    A1.x = 200;
}


int main() 
{
    clsA A1;

    A1.x = 50;

    cout << "\nA.x before calling function1: \n";
    A1.Print();

    //Pass by value, object will not be affected.
    Fun1(A1);

    cout << "\nA.x after calling function1 byval: \n";
    A1.Print();

    //Pass by reference, object will be affected.
    Fun2(A1);

    cout << "\nA.x after calling function2 byref: \n";
    A1.Print();

    system("pause>0");
}
```

</div>

الكائن `A1` يبدأ بالقيمة `50`.

عند استدعاء:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
Fun1(A1);
```

</div>

يتم التمرير **بالقيمة**، لذلك لا تتغير قيمة `A1.x` في الكائن الأصلي، وتبقى `50`.

بعد ذلك يتم استدعاء:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
Fun2(A1);
```

</div>

وهنا يتم التمرير **بالمرجع**، لذلك تتغير قيمة `A1.x` في الكائن الأصلي إلى `200`.

---

## 📌 الفرق بين ByVal وByRef

| ByVal | ByRef |
|---|---|
| يمرر الكائن بالقيمة | يمرر الكائن بالمرجع |
| التعديل داخل الدالة لا ينعكس على الكائن الأصلي | التعديل داخل الدالة ينعكس على الكائن الأصلي |
| مثال: `void Fun1(clsA A1)` | مثال: `void Fun2(clsA &A1)` |

---

## ⚠️ ملاحظة مهمة

الفرق الأساسي يظهر عند تعديل بيانات الكائن داخل الدالة:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
A1.x = 100;
```

</div>

في `Fun1` لا تتغير قيمة الكائن الأصلي لأن التمرير **ByVal**.

أما في `Fun2`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
A1.x = 200;
```

</div>

فتتغير قيمة الكائن الأصلي لأن التمرير **ByRef**.

---

## 💡 الفكرة الأساسية

الكائنات يمكن تمريرها إلى الدوال مثل أنواع البيانات الأخرى.

- **ByVal:** التعديل داخل الدالة لا يغيّر الكائن الأصلي.
- **ByRef:** التعديل داخل الدالة يغيّر الكائن الأصلي.

---

## 🔑 الملخص

- يمكن تمرير الكائنات إلى الدوال.
- يمكن تمرير الكائن **ByVal** أو **ByRef**.
- `void Fun1(clsA A1)` يستخدم **ByVal**.
- `void Fun2(clsA &A1)` يستخدم **ByRef**.
- **ByVal** لا ينعكس على الكائن الأصلي.
- **ByRef** ينعكس على الكائن الأصلي.

</div>

## 📝 Introduction

Objects can be treated like any other data type such as `int`, `bool`, and `string`. Objects can be passed to functions as parameters in two ways: **by value (ByVal)** or **by reference (ByRef)**.

---

## 🧠 Quick Recap

The class `clsA` contains a public variable named `x` and a member function named `Print()` to display the value of `x`.

```cpp
class clsA
{

public:
    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};
```

---

## 🎯 Definition: Passing Objects to Functions

> **Passing Objects to Functions**
>
> Passing an object from a class to a function as a parameter, either **by value (ByVal)** or **by reference (ByRef)**.

---

## ⚙️ Passing by Value (ByVal)

When an object is passed by value, a copy of the object is sent to the function. So, any update to the object inside the function does not affect the original object.

```cpp
void Fun1(clsA A1)
{

    A1.x = 100;
}
```

Here, `A1` is passed to `Fun1` **by value**.

When `A1.x` becomes `100` inside `Fun1`, the update does not change the original object in `main`.

---

## ⚙️ Passing by Reference (ByRef)

When an object is passed by reference, the original object is used inside the function. So, any update to it affects the original object.

```cpp
void Fun2(clsA &A1)
{

    A1.x = 200;
}
```

The `&` in `clsA &A1` means that the object is passed **by reference**.

So, when `A1.x` becomes `200` inside `Fun2`, the `x` value in the original object also changes.

---

## 💻 Example

The complete code:

```cpp
#include<iostream>

using namespace std;

class clsA
{

public:
    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};


//object sent by value, any updated will not b reflected
// on the original object
void Fun1(clsA A1)
{

    A1.x = 100;
}


//object sent by reference, any updated will be reflected
// on the original object
void Fun2(clsA &A1)
{

    A1.x = 200;
}


int main() 
{
    clsA A1;

    A1.x = 50;

    cout << "\nA.x before calling function1: \n";
    A1.Print();

    //Pass by value, object will not be affected.
    Fun1(A1);

    cout << "\nA.x after calling function1 byval: \n";
    A1.Print();

    //Pass by reference, object will be affected.
    Fun2(A1);

    cout << "\nA.x after calling function2 byref: \n";
    A1.Print();

    system("pause>0");
}
```

The object `A1` starts with the value `50`.

When this is called:

```cpp
Fun1(A1);
```

the object is passed **by value**, so the `A1.x` value in the original object does not change. It stays `50`.

Then this is called:

```cpp
Fun2(A1);
```

Here the object is passed **by reference**, so the `A1.x` value in the original object changes to `200`.

---

## 📌 Difference Between ByVal and ByRef

| ByVal | ByRef |
|---|---|
| Passes the object by value | Passes the object by reference |
| An update inside the function does not affect the original object | An update inside the function affects the original object |
| Example: `void Fun1(clsA A1)` | Example: `void Fun2(clsA &A1)` |

---

## ⚠️ Important Note

The main difference appears when the object's data is updated inside the function:

```cpp
A1.x = 100;
```

In `Fun1`, the original object does not change because the object is passed **ByVal**.

But in `Fun2`:

```cpp
A1.x = 200;
```

the original object changes because the object is passed **ByRef**.

---

## 💡 Key Idea

Objects can be passed to functions like other data types.

- **ByVal:** an update inside the function does not change the original object.
- **ByRef:** an update inside the function changes the original object.

---

## 🔑 Summary

- Objects can be passed to functions.
- An object can be passed **ByVal** or **ByRef**.
- `void Fun1(clsA A1)` uses **ByVal**.
- `void Fun2(clsA &A1)` uses **ByRef**.
- **ByVal** does not affect the original object.
- **ByRef** affects the original object.
