# Adding Objects to Vector

[English ↙](#english)

<div dir="rtl" style="text-align:right;font-family:'Arial',sans-serif;">

## 📝 مقدمة

يمكن استخدام `vector` لتخزين الكائنات، تمامًا كما يمكن استخدامه لتخزين أنواع البيانات الأخرى. في المثال هنا، يتم إنشاء `vector` من نوع `clsA`، ثم إضافة عدة كائنات إليه، وبعد ذلك الوصول إلى كل كائن واستدعاء دالة `Print()` الخاصة به.

---

## 🧠 مراجعة سريعة

الفئة `clsA` تحتوي على متغيّر `x` ودالة عضو `()Print`. كما تحتوي على **Parameterized Constructor** يستقبل `value` ويضعه في `x`.

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsA
{
public:
    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};
```
</div>

---

## 🎯 التعريف: Adding Objects to Vector

> **Adding Objects to Vector**
>
> هو إنشاء `vector` لتخزين كائنات من فئة معينة، ثم إضافة هذه الكائنات إليه والوصول إليها باستخدام الفهرس.

---

## ⚙️ إنشاء Vector من الكائنات

لإنشاء `vector` يخزن كائنات من الفئة `clsA`، نكتب:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
vector <clsA> v1;
```
</div>

هنا `v1` هو `vector` مخصص لتخزين كائنات من نوع `clsA`.

كما تم تحديد عدد الكائنات المطلوب إضافتها:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
short NumberOfObjects = 5;
```
</div>

---

## ⚙️ إضافة الكائنات باستخدام `()push_back`

يتم استخدام حلقة `for` لإضافة خمسة كائنات إلى نهاية الـ `vector`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
// inserting object at the end of vector
for (int i = 0; i < NumberOfObjects; i++)
{
    v1.push_back(clsA(i));
}
```
</div>

في كل دورة يتم إنشاء كائن من `clsA` باستخدام `clsA(i)`، ثم تتم إضافته إلى نهاية `v1` بواسطة `()push_back`.

بما أن قيمة `i` تبدأ من `0` وتصل إلى `4`، يتم إضافة خمسة كائنات، وتكون قيم `x` الخاصة بها `0` و`1` و`2` و`3` و`4`.

---

## ⚙️ الوصول إلى الكائنات داخل Vector

بعد إضافة الكائنات، يمكن الوصول إلى كل كائن باستخدام الفهرس ثم استدعاء `()Print`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
// printing object content
for (int i = 0; i < NumberOfObjects; i++)
{
    v1[i].Print();

}
```

</div>


`v1[i]` يشير إلى الكائن الموجود في الموضع `i` داخل الـ `vector`، و`().Print` تستدعي دالة `()Print` لذلك الكائن.

---

## 💻 مثال

الكود الكامل:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud
#include<iostream>
#include<vector>

using namespace std;

class clsA
{
public:
    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x <<endl;
    }

};


int main() 

{
    
    vector <clsA> v1;
    short NumberOfObjects=5;

    // inserting object at the end of vector
    for (int i = 0; i < NumberOfObjects; i++)
    {
        v1.push_back(clsA(i));
    }

    // printing object content
    for (int i = 0; i < NumberOfObjects; i++)
    {
        v1[i].Print();

    }

    system("pause>0");

}
```
</div>

البرنامج ينشئ `vector` اسمه `v1` لتخزين كائنات `clsA`. ثم يضيف خمسة كائنات باستخدام `()push_back`. بعد ذلك يمر على الكائنات ويستدعي `()Print` لكل واحد منها.

---

## 📌 الفكرة الأساسية في المثال

هناك خطوتان أساسيتان:

**1. إضافة الكائنات:**

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
v1.push_back(clsA(i));
```
</div>

هذه تضيف كائنًا جديدًا من `clsA` إلى نهاية الـ `vector`.

**2. الوصول إلى الكائنات:**

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
v1[i].Print();
```
</div>

هذه تصل إلى الكائن الموجود عند الفهرس `i` ثم تستدعي `()Print`.

---

## ⚠️ ملاحظة مهمة

يجب أن يكون نوع الـ `vector` هو نفس نوع الكائنات التي تريد تخزينها. في المثال:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
vector <clsA> v1;
```
</div>

لذلك تكون العناصر داخل `v1` من نوع `clsA`.

كما أن `()push_back` هنا تضيف الكائن في **نهاية** الـ `vector`، كما هو موضح في التعليق داخل الكود.

---

## 💡 الفكرة الأساسية

يمكن للـ `vector` أن يخزن كائنات من فئة معينة. في المثال، `vector <clsA> v1` يخزن كائنات `clsA`، و`()push_back` تضيف الكائنات، بينما `()v1[i].Print` تصل إلى كل كائن وتستدعي دالته.

---

## 🔑 ملخص

- يمكن تخزين الكائنات داخل `vector`.
- `;vector <clsA> v1` ينشئ `vector` لتخزين كائنات `clsA`.
- `()push_back` تضيف الكائن في نهاية الـ `vector`.
- `clsA(i)` ينشئ كائنًا باستخدام الـ Parameterized Constructor.
- `v1[i]` يصل إلى الكائن الموجود عند الفهرس `i`.
- `()v1[i].Print` تستدعي `()Print` للكائن الموجود في ذلك الموضع.

## 📝 Introduction

A `vector` can be used to store objects, just like it can store other data types. In this example, a `vector` of `clsA` objects is created, several objects are added to it, and then each object is accessed and its `Print()` member function is called.

---

## 🧠 Quick Recap

The class `clsA` contains a variable `x` and a member function `Print()`. It also has a **Parameterized Constructor** that receives `value` and assigns it to `x`.

```cpp
class clsA
{
public:
    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x << endl;
    }

};
```

---

## 🎯 Definition: Adding Objects to Vector

> **Adding Objects to Vector**
>
> Creating a `vector` to store objects of a certain class, then adding these objects to it and accessing them by index.

---

## ⚙️ Creating a Vector of Objects

To create a `vector` that stores objects of `clsA`, we write:

```cpp
vector <clsA> v1;
```

Here, `v1` is a `vector` for storing objects of type `clsA`.

The number of objects to add is also defined:

```cpp
short NumberOfObjects = 5;
```

---

## ⚙️ Adding Objects Using `push_back()`

A `for` loop is used to add five objects to the end of the `vector`:

```cpp
// inserting object at the end of vector
for (int i = 0; i < NumberOfObjects; i++)
{
    v1.push_back(clsA(i));
}
```

In each loop, an object of `clsA` is created using `clsA(i)`, then it is added to the end of `v1` using `push_back()`.

Because `i` starts from `0` and goes to `4`, five objects are added, and their `x` values are `0`, `1`, `2`, `3`, and `4`.

---

## ⚙️ Accessing Objects Inside the Vector

After adding the objects, each object can be accessed by index and its `Print()` function can be called:

```cpp
// printing object content
for (int i = 0; i < NumberOfObjects; i++)
{
    v1[i].Print();

}
```

`v1[i]` refers to the object at position `i` inside the `vector`, and `.Print()` calls the `Print()` function of that object.

---

## 💻 Example

The complete code:

```cpp
//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud
#include<iostream>
#include<vector>

using namespace std;

class clsA
{
public:
    //Parametarized Constructor
    clsA(int value)
    {
        x = value;
    }

    int x;

    void Print()
    {
        cout << "The value of x=" << x <<endl;
    }

};


int main() 

{
    
    vector <clsA> v1;
    short NumberOfObjects=5;

    // inserting object at the end of vector
    for (int i = 0; i < NumberOfObjects; i++)
    {
        v1.push_back(clsA(i));
    }

    // printing object content
    for (int i = 0; i < NumberOfObjects; i++)
    {
        v1[i].Print();

    }

    system("pause>0");

}
```

The program creates a `vector` named `v1` for storing `clsA` objects. It then adds five objects using `push_back()`. After that, it goes through the objects and calls `Print()` for each one.

---

## 📌 Main Idea in the Example

There are two main steps:

**1. Adding objects:**

```cpp
v1.push_back(clsA(i));
```

This adds a new `clsA` object to the end of the `vector`.

**2. Accessing objects:**

```cpp
v1[i].Print();
```

This accesses the object at index `i` and then calls `Print()`.

---

## ⚠️ Important Note

The type of the `vector` should be the same as the type of the objects you want to store. In this example:

```cpp
vector <clsA> v1;
```

So, the elements inside `v1` are of type `clsA`.

Also, `push_back()` adds the object to the **end** of the `vector`, as shown by the comment in the code.

---

## 💡 Key Idea

A `vector` can store objects of a certain class. In this example, `vector <clsA> v1` stores `clsA` objects, `push_back()` adds the objects, and `v1[i].Print()` accesses each object and calls its function.

---

## 🔑 Summary

- Objects can be stored inside a `vector`.
- `vector <clsA> v1;` creates a `vector` for storing `clsA` objects.
- `push_back()` adds an object to the end of the `vector`.
- `clsA(i)` creates an object using the Parameterized Constructor.
- `v1[i]` accesses the object at index `i`.
- `v1[i].Print()` calls `Print()` for the object at that position.
