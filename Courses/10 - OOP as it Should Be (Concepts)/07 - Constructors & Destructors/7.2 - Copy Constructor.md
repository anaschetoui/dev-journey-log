# Copy Constructor

---

## 📝 مقدمة

بعد تعلّم `Constructor`، نحتاج إلى فهم حالة أخرى: إنشاء كائن جديد اعتمادًا على كائن موجود مسبقًا.

في هذه الحالة، يتم نسخ البيانات الموجودة في الكائن القديم إلى الكائن الجديد. هذه العملية ترتبط بـ `Copy Constructor`.

---

## 🧠 مراجعة سريعة

الـ `Constructor` يتم استدعاؤه عند إنشاء `Object`.

يمكن أن يكون لدينا `Parameterized Constructor` يستقبل البيانات عند إنشاء الكائن.

في هذا الدرس، ننتقل إلى حالة إنشاء كائن جديد من كائن موجود بالفعل.

---

## 🎯 تعريف: Copy Constructor

> **Copy Constructor**
>
> دالة بانية تُستخدم لإنشاء `Object` جديد اعتمادًا على `Object` موجود، وذلك عن طريق نسخ البيانات من الكائن القديم إلى الكائن الجديد.

---

## ⚙️ كيف يعمل Copy Constructor

عندما نكتب:

`;clsAddress Address2 = Address1`

فإن `Address2` يتم إنشاؤه اعتمادًا على `Address1`.

يتم أخذ البيانات الموجودة في `Address1` ووضع نسخة منها في `Address2`.

في المثال، البيانات التي يتم نسخها هي:

- `AddressLine1_`
- `AddressLine2_`
- `POBox_`
- `ZipCode_`    

وبعد عملية النسخ، يكون لكل كائن بياناته الخاصة.

---

## 💻 مثال: Copy Constructor في `clsAddress`

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
#include <iostream>
using namespace std;

class clsAddress
{
private:

    string _AddressLine1;
    string _AddressLine2;
    string _POBox;
    string _ZipCode;

public:

    clsAddress( string AddressLine1, string AddressLine2, string POBox, string ZipCode)
    {
        _AddressLine1 = AddressLine1;
        _AddressLine2 = AddressLine2;
        _POBox = POBox;
        _ZipCode = ZipCode;
    }

    // Copy Constructor
    clsAddress(clsAddress &old_obj)
    {
        _AddressLine1 = old_obj.AddressLine1();
        _AddressLine2 = old_obj.AddressLine2();
        _POBox = old_obj.POBox();
        _ZipCode = old_obj.ZipCode();
    }

    void SetAddressLine1(string AddressLine1)
    {
        _AddressLine1 = AddressLine1;
    }

    string AddressLine1()
    {
        return _AddressLine1;
    }

    void SetAddressLine2(string AddressLine2)
    {
        _AddressLine2 = AddressLine2;
    }

    string AddressLine2()
    {
        return _AddressLine2;
    }

    void SetPOBox(string POBox)
    {
        _POBox = POBox;
    }

    string POBox()
    {
        return _POBox;
    }

    void SetZipCode(string ZipCode)
    {
        _ZipCode = ZipCode;
    }

    string ZipCode()
    {
        return _ZipCode;
    }

    void Print()
    {
        cout << "\nAddress Details:\n";
        cout << "------------------------";
        cout << "\nAddressLine1: " << _AddressLine1 << endl;
        cout << "AddressLine2: " << _AddressLine2 << endl;
        cout << "POBox : " << _POBox << endl;
        cout << "ZipCode : " << _ZipCode << endl;
    }
};

int main()
{
    clsAddress Address1("Queen Alia Street", "B 303", "11192", "5555");

    Address1.Print();

    clsAddress Address2 = Address1;

    Address2.Print();

    system("pause>0");
    return 0;
}
```

</div>

في هذا المثال، يوجد `Copy Constructor` اسمه `clsAddress` لأنه يحمل نفس اسم الـ `Class`.

يستقبل الكائن القديم من النوع `clsAddress`، ثم يأخذ بياناته ويضعها في بيانات الكائن الجديد.

عند تنفيذ:

`clsAddress Address2 = Address1;`

يتم إنشاء `Address2` ونسخ بيانات `Address1` إليه.

---

## 📌 Copy Constructor الذي ينشئه الـ Compiler

إذا لم نكتب `Copy Constructor` بأنفسنا، يقوم الـ compiler بإنشائه لنا.

لذلك وجود `Copy Constructor` في الكود ليس ضروريًا دائمًا.

يمكن حذف `Copy Constructor` من المثال، وسيظل النسخ موجودًا لأن الـ compiler يوفره.

الهدف هنا هو فهم ما يحدث عندما يتم نسخ كائن إلى كائن آخر.

---

## ⚙️ Parameter في Copy Constructor

في المثال، يأخذ `Copy Constructor` كائنًا قديمًا من نفس النوع:

`clsAddress(clsAddress &old_obj)`

هذا يسمح بالوصول إلى بيانات `old_obj`، ثم نسخها إلى الكائن الجديد.

مثلًا:

`old_obj.AddressLine1()`

تعطي قيمة `AddressLine1` الموجودة في الكائن القديم.

ويتم الأمر نفسه مع باقي البيانات.

---

## 📌 Old Object و New Object

يمكن التفكير في العملية بهذه الطريقة:

- `Address1` هو الـ `Old Object`.
- `Address2` هو الـ `New Object`.
- بيانات `Address1` تُنسخ إلى `Address2`.

الفكرة نفسها يمكن استخدامها مع `Class` أخرى.

إذا كان لدينا `Employee2` تم إنشاؤه اعتمادًا على `Employee1`، فإن `Employee1` يمثل الكائن القديم الذي تأتي منه البيانات.

---

## 📚 المصطلحات

| المصطلح | المعنى |
|---|---|
| Copy Constructor | دالة بانية تُستخدم لإنشاء كائن جديد بنسخ بيانات كائن موجود |
| Old Object | الكائن الموجود الذي نأخذ منه البيانات |
| New Object | الكائن الجديد الذي يستقبل نسخة من البيانات |
| Copy | نسخ البيانات من كائن إلى آخر |

---

## ⚠️ ملاحظات

- `Copy Constructor` يحمل نفس اسم الـ `Class`.
- يتم استخدامه عند إنشاء كائن اعتمادًا على كائن موجود.
- في المثال، `Address1` هو الكائن القديم و`Address2` هو الكائن الجديد.
- يتم نسخ بيانات العنوان من `Address1` إلى `Address2`.
- إذا لم نكتب `Copy Constructor`، يمكن للـ compiler إنشاؤه لنا.
- كتابة `Copy Constructor` يدويًا في هذا المثال هدفها فهم ما يحدث أثناء عملية النسخ.

---

## 💡 الفكرة الأساسية

`Copy Constructor` يعني إنشاء كائن جديد بنسخ بيانات كائن موجود.

في المثال:

`clsAddress Address2 = Address1;`

تعني أن `Address2` يتم إنشاؤه اعتمادًا على `Address1`، ويتم نسخ بيانات `Address1` إليه.

---

## 🔑 ملخص

- `Copy Constructor` ينشئ كائنًا جديدًا اعتمادًا على كائن موجود.
- يتم نسخ بيانات الكائن القديم إلى الكائن الجديد.
- `Address1` هو الكائن القديم و`Address2` هو الكائن الجديد في المثال.
- يمكن كتابة `Copy Constructor` يدويًا لفهم عملية النسخ.
- إذا لم نكتبه، يقوم الـ compiler بإنشائه لنا.
- السطر `clsAddress Address2 = Address1;` هو الحالة المستخدمة في المثال لنسخ الكائن.

## 📝 Introduction

After learning about `Constructor`, we need to understand another case: creating a new object from an existing object.

In this case, the data in the old object is copied to the new object. This is related to the `Copy Constructor`.

---

## 🧠 Quick Recap

A `Constructor` is called when an `Object` is created.

We can have a `Parameterized Constructor` that receives data when the object is created.

In this lesson, we move to a case where a new object is created from an object that already exists.

---

## 🎯 Definition: Copy Constructor

> **Copy Constructor**
>
> A constructor used to create a new `Object` from an existing `Object` by copying the data from the old object to the new object.

---

## ⚙️ How a Copy Constructor Works

When we write:

`clsAddress Address2 = Address1;`

`Address2` is created from `Address1`.

The data in `Address1` is copied to `Address2`.

In the example, the copied data is:

- `_AddressLine1`
- `_AddressLine2`
- `_POBox`
- `_ZipCode`

After the copy, each object has its own data.

---

## 💻 Example: Copy Constructor in `clsAddress`

```cpp
#include <iostream>
using namespace std;

class clsAddress
{
private:

    string _AddressLine1;
    string _AddressLine2;
    string _POBox;
    string _ZipCode;

public:

    clsAddress(string AddressLine1, string AddressLine2, string POBox, string ZipCode)
    {
        _AddressLine1 = AddressLine1;
        _AddressLine2 = AddressLine2;
        _POBox = POBox;
        _ZipCode = ZipCode;
    }

    // Copy Constructor
    clsAddress(clsAddress &old_obj)
    {
        _AddressLine1 = old_obj.AddressLine1();
        _AddressLine2 = old_obj.AddressLine2();
        _POBox = old_obj.POBox();
        _ZipCode = old_obj.ZipCode();
    }

    void SetAddressLine1(string AddressLine1)
    {
        _AddressLine1 = AddressLine1;
    }

    string AddressLine1()
    {
        return _AddressLine1;
    }

    void SetAddressLine2(string AddressLine2)
    {
        _AddressLine2 = AddressLine2;
    }

    string AddressLine2()
    {
        return _AddressLine2;
    }

    void SetPOBox(string POBox)
    {
        _POBox = POBox;
    }

    string POBox()
    {
        return _POBox;
    }

    void SetZipCode(string ZipCode)
    {
        _ZipCode = ZipCode;
    }

    string ZipCode()
    {
        return _ZipCode;
    }

    void Print()
    {
        cout << "\nAddress Details:\n";
        cout << "------------------------";
        cout << "\nAddressLine1: " << _AddressLine1 << endl;
        cout << "AddressLine2: " << _AddressLine2 << endl;
        cout << "POBox : " << _POBox << endl;
        cout << "ZipCode : " << _ZipCode << endl;
    }
};

int main()
{
    clsAddress Address1("Queen Alia Street", "B 303", "11192", "5555");

    Address1.Print();

    clsAddress Address2 = Address1;

    Address2.Print();

    system("pause>0");
    return 0;
}
```

In this example, the `Copy Constructor` is called `clsAddress` because it has the same name as the `Class`.

It receives the old object as a `clsAddress` and copies its data into the new object.

When we write:

`clsAddress Address2 = Address1;`

`Address2` is created and the data from `Address1` is copied into it.

---

## 📌 The Copy Constructor Created by the Compiler

If we do not write a `Copy Constructor` ourselves, the compiler creates one for us.

So a `Copy Constructor` is not always necessary to write manually.

We can remove the `Copy Constructor` from this example, and copying will still be available because the compiler provides it.

The purpose here is to understand what happens when one object is copied to another.

---

## ⚙️ Parameter in a Copy Constructor

In the example, the `Copy Constructor` receives an old object of the same type:

`clsAddress(clsAddress &old_obj)`

This lets it access the data of `old_obj` and copy it to the new object.

For example:

`old_obj.AddressLine1()`

returns the `AddressLine1` value from the old object.

The same idea is used for the other data.

---

## 📌 Old Object and New Object

We can think about the operation like this:

- `Address1` is the `Old Object`.
- `Address2` is the `New Object`.
- The data of `Address1` is copied to `Address2`.

The same idea can be used with another `Class`.

If `Employee2` is created from `Employee1`, then `Employee1` is the old object from which the data comes.

---

## 📚 Terminology

| Term | Meaning |
|---|---|
| Copy Co nstructor | A constructor used to create a new object by copying data from an existing object |
| Old Object | The existing object from which the data is copied |
| New Object | The new object that receives a copy of the data |
| Copy | Copying data from one object to another |

---

## ⚠️ Notes

- A `Copy Constructor` has the same name as the `Class`.
- It is used when one object is created from an existing object.
- In the example, `Address1` is the old object and `Address2` is the new object.
- The address data is copied from `Address1` to `Address2`.
- If we do not write a `Copy Constructor`, the compiler can create one for us.
- Writing it manually in this example is mainly for understanding the copy process.

---

## 💡 Key Idea

A `Copy Constructor` means creating a new object by copying data from an existing object.

In the example:

`clsAddress Address2 = Address1;`

means that `Address2` is created from `Address1`, and the data of `Address1` is copied to it.

---

## 🔑 Summary

- A `Copy Constructor` creates a new object from an existing object.
- The data of the old object is copied to the new object.
- `Address1` is the old object and `Address2` is the new object in the example.
- We can write a `Copy Constructor` manually to understand the copy process.
- If we do not write it, the compiler creates one for us.
- `clsAddress Address2 = Address1;` is the copy operation used in the example.
