# الدالة البانية (Constructor)

---

## 📝 مقدمة

الـ `Constructor` مفهوم مهم داخل الـ `Class`. يتم استدعاؤه تلقائيًا عند إنشاء `Object` من الـ `Class`.

في هذا الدرس، نستخدمه لمنع إنشاء `Object` فارغ، وإجبار المستخدم على إرسال البيانات المطلوبة عند إنشاء الكائن.

---

## 🧠 مراجعة سريعة

في الدروس السابقة، أصبح لدينا Class تحتوي على private members وProperties للوصول إلى البيانات وتعديلها.

في هذا الدرس، نضيف Constructor حتى نتحكم في تهيئة الـ Object عند إنشائه، بدل أن نتركه فارغًا.

---

## 🎯 تعريف: Constructor

> **Constructor (الدالة البانية)**
>
> دالة خاصة داخل الـ `Class` تحمل نفس اسم الـ `Class`، ويتم استدعاؤها تلقائيًا عند إنشاء `Object` من هذه الـ `Class`.

---

## ⚙️ Default Constructor

إذا لم نكتب `Constructor` داخل الـ `Class`، يقوم الـ compiler بإنشاء `Default Constructor` تلقائيًا.

الـ `Default Constructor` لا يحتاج إلى parameters، ولذلك يسمح بإنشاء `Object` دون إرسال بيانات.

في الدرس، تم توضيح أن هذا قد يؤدي إلى إنشاء `Object` فارغ، وهو أمر لا نريده.

---

## 💻 مثال: Constructor في `clsAddress`

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
#include <iostream>
using namespace std;

class clsAddress
{
private:

    string _AddressLine1;
    string _AddressLine2;
    string _POBox;
    string _ZipCode;

public:

    clsAddress(string AddressLine1, string AddressLine2, string POBox, string ZipCode)
    {
        _AddressLine1 = AddressLine1;
        _AddressLine2 = AddressLine2;
        _POBox = POBox;
        _ZipCode = ZipCode;
    }

    void SetAddressLine1(string AddressLine1)
    {
        _AddressLine1 = AddressLine1;
    }

    string AddressLine1()
    {
        return _AddressLine1;
    }

    void SetAddressLine2(string AddressLine2)
    {
        _AddressLine2 = AddressLine2;
    }

    string AddressLine2()
    {
        return _AddressLine2;
    }

    void SetPOBox(string POBox)
    {
        _POBox = POBox;
    }

    string POBox()
    {
        return _POBox;
    }

    void SetZipCode(string ZipCode)
    {
        _ZipCode = ZipCode;
    }

    string ZipCode()
    {
        return _ZipCode;
    }

    void Print()
    {
        cout << "Address Details:";
        cout << "------------------------";
        cout << "AddressLine1: " << _AddressLine1 << endl;
        cout << "AddressLine2: " << _AddressLine2 << endl;
        cout << "POBox : " << _POBox << endl;
        cout << "ZipCode : " << _ZipCode << endl;
    }
};

int main()
{
    clsAddress Address1("Queen Alia Street","B 303","11192","5555");

    Address1.Print();

    return 0;
};
```

</div>

في هذا المثال، `clsAddress` تحتوي على `Constructor` اسمه `clsAddress`، وهو نفس اسم الـ `Class`.

يستقبل الـ `Constructor` أربعة parameters:

- `AddressLine1`
- `AddressLine2`
- `POBox`
- `ZipCode`

ثم يضع هذه القيم في الـ `private members` الخاصة بالكائن.

عند إنشاء `Address1` يتم إرسال القيم الأربع مباشرة:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

`clsAddress Address1("Queen Alia Street","B 303","11192","5555");`
</div>

---

## ⚙️ استدعاء الـ Constructor

يتم استدعاء الـ `Constructor` بمجرد إنشاء `Object`.

عند تنفيذ إنشاء `Address1`، يتم استدعاء `clsAddress` وإرسال القيم الأربع إليه، ثم تُخزّن القيم داخل أعضاء الـ `Object`.

---

## 📌 لماذا نستخدم Constructor؟

يمكن استخدام الـ `Constructor` لوضع `Initial Values` للكائن عند إنشائه.

كما يمكن استخدامه لتنفيذ عمليات أولية عند إنشاء الـ `Object`، مثل الحصول على معلومات من `Database` أو `File`، كما ورد في الدرس.

---

## ⚠️ ماذا يحدث عند تعريف Constructor خاص؟

عندما نعرّف `Constructor` يحتاج إلى parameters، لا يعود الـ `Default Constructor` الذي كان يسمح بإنشاء `Object` فارغ متاحًا بالطريقة السابقة.

لذلك، إذا حاولنا إنشاء `Object` دون إرسال الـ parameters المطلوبة، سيظهر خطأ.

في `clsAddress` يجب إرسال بيانات العنوان الأربعة عند إنشاء الـ `Object`.

---

## 📌 منع الـ Object الفارغ

إذا كان وجود `Object` فارغ غير مناسب، يمكن استخدام `Constructor` لإجبار المستخدم على إرسال البيانات المطلوبة.

في `clsAddress`، لا يمكن إنشاء الكائن بالطريقة الفارغة بعد تعريف الـ `Constructor` الذي يحتاج إلى أربعة parameters.

وبذلك يتم إنشاء الـ `Object` مع البيانات المطلوبة.

---

## 📚 المصطلحات

| المصطلح | المعنى |
|---|---|
| Constructor | دالة تحمل اسم الـ `Class` ويتم استدعاؤها تلقائيًا عند إنشاء `Object` |
| Default Constructor | Constructor لا يحتاج إلى parameters ويتم إنشاؤه تلقائيًا |

---

## ⚠️ ملاحظات

- الـ `Constructor` يحمل نفس اسم الـ `Class`.
- لا يملك الـ `Constructor` نوع إرجاع.
- يتم استدعاؤه تلقائيًا عند إنشاء `Object`.
- الـ `Default Constructor` لا يحتاج إلى parameters.
- تعريف `Constructor` يحتاج إلى parameters يمنع إنشاء الـ `Object` بالطريقة الفارغة التي تعتمد على الـ `Default Constructor`.
- يمكن للـ `Constructor` إعطاء الـ `Object` قيمًا ابتدائية.
- يمكن استخدامه أيضًا لتنفيذ عمليات أولية عند إنشاء الـ `Object`.

---

## 💡 الفكرة الأساسية

الـ `Constructor` هو دالة تُستدعى تلقائيًا عند إنشاء `Object`.

إذا لم نكتب Constructor، يمكن للـ compiler إنشاء `Default Constructor`.

أما إذا أردنا إجبار المستخدم على إرسال بيانات، فنعرّف `Constructor` يستقبل الـ parameters المطلوبة.

---

## 🔑 ملخص

- الـ `Constructor` دالة تحمل نفس اسم الـ `Class`.
- يتم استدعاؤه تلقائيًا عند إنشاء `Object`.
- إذا لم نعرّف Constructor، يمكن للـ compiler إنشاء `Default Constructor`.
- الـ `Default Constructor` لا يحتاج إلى parameters.
- يمكن تعريف Constructor يستقبل parameters لإعطاء `Object` قيمًا عند إنشائه.
- في `clsAddress`، يستقبل الـ Constructor أربعة parameters خاصة بالعنوان.
- تعريف Constructor يحتاج إلى parameters يمنع إنشاء الـ `Object` بالطريقة الفارغة.
- يمكن استخدام الـ `Constructor` لتنفيذ عمليات أولية عند إنشاء الـ `Object`.

## 📝 Introduction

A `Constructor` is an important concept inside a `Class`. It is called automatically when an `Object` is created from the `Class`.

In this lesson, we use it to stop empty `Objects` and require the needed data when creating the object.

---

## 🧠 Quick Recap

In the previous lessons, we used Class with private members and Properties to control access to data.

In this lesson, we add a Constructor to control how the Object is initialized when it is created, instead of allowing it to stay empty.
---

## 🎯 Definition: Constructor

> **Constructor**
>
> A special function inside the `Class` with the same name as the `Class`. It is called automatically when an `Object` is created from the `Class`.

---

## ⚙️ Default Constructor

If we do not write a `Constructor` inside the `Class`, the compiler creates a `Default Constructor` automatically.

A `Default Constructor` does not need parameters, so it allows us to create an `Object` without sending data.

In the lesson, this was shown as a way to create an empty `Object`, which we do not want.

---

## 💻 Example: Constructor in `clsAddress`

```cpp
#include <iostream>
using namespace std;

class clsAddress
{
private:

    string _AddressLine1;
    string _AddressLine2;
    string _POBox;
    string _ZipCode;

public:

    clsAddress(
        string AddressLine1,
        string AddressLine2,
        string POBox,
        string ZipCode)
    {
        _AddressLine1 = AddressLine1;
        _AddressLine2 = AddressLine2;
        _POBox = POBox;
        _ZipCode = ZipCode;
    }

    void SetAddressLine1(string AddressLine1)
    {
        _AddressLine1 = AddressLine1;
    }

    string AddressLine1()
    {
        return _AddressLine1;
    }

    void SetAddressLine2(string AddressLine2)
    {
        _AddressLine2 = AddressLine2;
    }

    string AddressLine2()
    {
        return _AddressLine2;
    }

    void SetPOBox(string POBox)
    {
        _POBox = POBox;
    }

    string POBox()
    {
        return _POBox;
    }

    void SetZipCode(string ZipCode)
    {
        _ZipCode = ZipCode;
    }

    string ZipCode()
    {
        return _ZipCode;
    }

    void Print()
    {
        cout << "Address Details:";
        cout << "------------------------";
        cout << "AddressLine1: " << _AddressLine1 << endl;
        cout << "AddressLine2: " << _AddressLine2 << endl;
        cout << "POBox : " << _POBox << endl;
        cout << "ZipCode : " << _ZipCode << endl;
    }
};

int main()
{
    clsAddress Address1("Queen Alia Street", "B 303", "11192", "5555");

    Address1.Print();

    system("pause>0");
    return 0;
};
```

In this example, `clsAddress` has a `Constructor` called `clsAddress`, which is the same as the `Class` name.

The `Constructor` receives four parameters:

- `AddressLine1`
- `AddressLine2`
- `POBox`
- `ZipCode`

It then puts these values into the `private members` of the object.

When `Address1` is created, the four values are sent directly:

`clsAddress Address1("Queen Alia Street","B 303","11192","5555");`

---

## ⚙️ Calling the Constructor

The `Constructor` is called as soon as an `Object` is created.

When `Address1` is created, `clsAddress` is called and receives the four values. The values are then stored inside the members of the `Object`.

---

## 📌 Why Use a Constructor?

A `Constructor` can be used to give `Initial Values` to an object when it is created.

It can also be used for initial operations when the `Object` is created, such as getting information from a `Database` or a `File`.

---

## ⚠️ What Happens When We Define Our Own Constructor?

When we define a `Constructor` that needs parameters, the `Default Constructor` that allowed the empty form is no longer available in the previous way.

So, if we try to create an `Object` without sending the required parameters, we get an error.

In `clsAddress`, we must send the four address values when creating the `Object`.

---

## 📌 Preventing an Empty Object

If an empty `Object` is not suitable, we can use a `Constructor` to force the user to send the required data.

In `clsAddress`, we cannot create the object in the empty form after defining the `Constructor` that needs four parameters.

The `Object` is therefore created with the required data.

---

## 📚 Terminology

| Term | Meaning |
|---|---|
| Constructor | A function with the same name as the `Class`, called automatically when an `Object` is created |
| Default Constructor | A Constructor with no parameters, created automatically in the case described |

---

## ⚠️ Notes

- A `Constructor` has the same name as the `Class`.
- A `Constructor` has no return type.
- It is called automatically when an `Object` is created.
- A `Default Constructor` does not need parameters.
- Defining a `Constructor` with parameters prevents the empty form that depends on the `Default Constructor`.
- A `Constructor` can give an `Object` initial values.
- It can also be used for initial operations when an `Object` is created.

---

## 💡 Key Idea

A `Constructor` is a function that is called automatically when an `Object` is created.

If we do not write a Constructor, the compiler can create a `Default Constructor`.

If we want to force the user to send data, we define a `Constructor` that receives the required parameters.

---

## 🔑 Summary

- A `Constructor` has the same name as the `Class`.
- It is called automatically when an `Object` is created.
- If we do not define a Constructor, the compiler can create a `Default Constructor`.
- A `Default Constructor` does not need parameters.
- We can define a Constructor with parameters to give an `Object` values when it is created.
- In `clsAddress`, the Constructor receives four address parameters.
- Defining a Constructor with parameters prevents the empty form.
- A `Constructor` can also be used for initial operations when an `Object` is created.
