# Properties: Set و Get من خلال =

---

## 📝 مقدمة

في الدرس السابق، استخدمنا `Properties` للوصول إلى البيانات من خلال دوال `Set` و`Get`.

في هذا الدرس، نضيف طريقة أسهل للتعامل مع الـ `Property` من خلال علامة `=`. بدل كتابة `SetFirstName()` و`GetFirstName()` بشكل مباشر، يمكن استخدام `FirstName` مع الإسناد والحصول على القيمة.

---

## 🧠 مراجعة سريعة

لدينا متغيّر `private` اسمه `FirstName_`، ولدينا دالتان:

- `SetFirstName()` لتخزين القيمة في `FirstName_`.
- `GetFirstName()` لإرجاع القيمة من `FirstName_`.

من خارج الـ `Class` لا نصل مباشرة إلى `FirstName_`. نستخدم دوال `Set` و`Get` للتعامل معه.

---

## 🎯 تعريف: Property Mapping

> **Property Mapping**
>
> ربط اسم الـ `Property` بدالة `Get` ودالة `Set` حتى يتم استدعاء الدالة المناسبة عند استخدام الـ `Property`.
>
> عند استخدام `=` مع الـ `Property` يتم استدعاء دالة `Set`، وعند الحصول على القيمة يتم استدعاء دالة `Get`.

---

## ⚙️ كيف يعمل الـ Mapping

يمكن تعريف `Property` وربطها بدوال `Get` و`Set` باستخدام:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

 `__declspec(property(get = GetFirstName, put = SetFirstName))`
</div>

في هذا السطر:

- `get = GetFirstName` يربط الـ `Property` بدالة `()GetFirstName`.
- `put = SetFirstName` يربط الـ `Property` بدالة `()SetFirstName`.
- نوع الـ `Property` في المثال هو `string`.
- الاسم الذي نستخدمه مع الـ `Object` هو اسم الـ `Property`.

لذلك يمكن استخدام `FirstName` بدل استدعاء `()SetFirstName` و`()GetFirstName` بشكل مباشر.

---

## 💻 مثال: `FirstName`

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
#include <iostream>
using namespace std;

class clsPerson
{
private:
string _FirstName;

public:

void SetFirstName(string FirstName) 
{
	_FirstName = FirstName;
}

string GetFirstName()
{
	return _FirstName;
}

__declspec(property(get = GetFirstName, put = SetFirstName)) string FirstName;

};

int main()
{

clsPerson Person1;

Person1.SetFirstName("Mohammed");
cout << Person1.GetFirstName() <<endl;

//instead of the above we only write this

Person1.FirstName = "Mohammed";
cout << Person1.FirstName;



return 0;

};
```

</div>
</br>


في الجزء الأول من `()main` يتم استخدام الطريقة السابقة:

`;Person1.SetFirstName("Mohammed")`

ثم يتم الحصول على القيمة باستخدام:

`()Person1.GetFirstName`

بعد تعريف الـ `Property`، يمكن استخدام الطريقة المختصرة:

`;Person1.FirstName = "Mohammed"`

ثم:

`;cout << Person1.FirstName`

عند الإسناد إلى `FirstName`، يتم استدعاء `()SetFirstName` من خلال الـ mapping.

وعند الحصول على قيمة `FirstName`، يتم استدعاء `()GetFirstName` من خلال الـ mapping.

---

## 📌 اسم الـ Property

اسم الـ `Property` هو الاسم الذي نستخدمه من خلال الـ `Object`.

في المثال، اسمها `FirstName`.

يمكن أن يكون اسم الـ `Property` مختلفًا، لكن من الأفضل أن يكون الاسم واضحًا ومعبّرًا عن البيانات التي يمثلها.

---

## 📌 نوع الـ Property

في المثال، نوع `FirstName` هو `string` لأن `()GetFirstName` تُرجع قيمة من نوع `string`.

إذا كانت الـ `Property` تتعامل مع قيمة من نوع آخر، يتم استخدام النوع المناسب لها.

---

## 📌 Set و Get

الدوال `Set` و`Get` لا تختفي عند استخدام الـ `Property`.

هي ما زالت موجودة داخل الـ `Class`:

- `()SetFirstName` تخزّن القيمة.
- `()GetFirstName` تُرجع القيمة.

الـ `Property` تجعل الوصول إليهما أسهل من خلال اسم واحد.

---

## 📚 المصطلحات

| المصطلح | المعنى |
|---|---|
| Property | اسم يُستخدم للوصول إلى البيانات من خلال `Get` و`Set` |
| Property Mapping | ربط الـ `Property` بدوال `Get` و`Set` |
| Get | دالة تُرجع القيمة |
| Set | دالة تخزّن أو تغيّر القيمة |
| `get` | جزء من تعريف الـ `Property` يحدد دالة الحصول على القيمة |
| `put` | جزء من تعريف الـ `Property` يحدد دالة الإسناد |
| `__declspec(property(...))` | صياغة تُستخدم لتعريف وربط الـ `Property`  |
| Assignment | إسناد قيمة باستخدام `=` |


---

## ⚠️ ملاحظات

- استخدام `Property` لا يلغي دوال `Set` و`Get`.
- `=` مع الـ `Property` يؤدي إلى استدعاء دالة `Set` المرتبطة بها.
- الحصول على قيمة الـ `Property` يؤدي إلى استدعاء دالة `Get` المرتبطة بها.
- في المثال، `FirstName` مرتبطة بـ `GetFirstName()` و`SetFirstName()`.
- الاسم المستخدم مع الـ `Object` هو اسم الـ `Property`، وليس اسم الـ `private member`.
- `_FirstName` يبقى `private` ولا يتم الوصول إليه مباشرة من خارج الـ `Class`.
- السطر `__declspec(property(...))` يقوم بعملية الـ mapping بين الـ `Property` ودوال `Get` و`Set` في هذا المثال.

---

## 💡 الفكرة الأساسية

بدل كتابة:

`;Person1.SetFirstName("Mohammed")`

و:

`;()Person1.GetFirstName`

يمكن استخدام:

`;"Person1.FirstName = "Mohammed`

و:

`Person1.FirstName`

لأن الـ `Property` تربط عملية الإسناد بدالة `Set`، وربط الحصول على القيمة بدالة `Get`.

---

## 🔑 ملخص

- يمكن استخدام `Properties` بطريقة أسهل من خلال `=`.
- `get = GetFirstName` يربط الـ `Property` بدالة `GetFirstName()`.
- `put = SetFirstName` يربط الـ `Property` بدالة `SetFirstName()`.
- عند الإسناد إلى `FirstName` يتم استخدام `SetFirstName()`.
- عند الحصول على قيمة `FirstName` يتم استخدام `GetFirstName()`.
- دوال `Set` و`Get` تبقى موجودة، والـ `Property` توفر طريقة أسهل للوصول إليها.
- `__declspec(property(...))` هو السطر المستخدم لعمل الـ mapping في هذا المثال.

## 📝 Introduction

In the previous lesson, we used `Properties` to access data through `Set` and `Get` functions.

In this lesson, we add an easier way to work with a `Property` through the `=` sign. Instead of writing `SetFirstName()` and `GetFirstName()` directly, we can use `FirstName` with assignment and getting the value.

---

## 🧠 Quick Recap

We have a `private` variable called `_FirstName`, and we have two functions:

- `SetFirstName()` stores the value in `_FirstName`.
- `GetFirstName()` returns the value from `_FirstName`.

From outside the `Class`, we do not access `_FirstName` directly. We use the `Set` and `Get` functions to work with it.

---

## 🎯 Definition: Property Mapping

> **Property Mapping**
>
> Linking a `Property` name to a `Get` function and a `Set` function so the correct function is called when the `Property` is used.
>
> When `=` is used with the `Property`, the `Set` function is called. When the value is read, the `Get` function is called.

---

## ⚙️ How the Mapping Works

A `Property` can be defined and linked to `Get` and `Set` functions using:

`__declspec(property(get = GetFirstName, put = SetFirstName))`

In this line:

- `get = GetFirstName` links the `Property` to `GetFirstName()`.
- `put = SetFirstName` links the `Property` to `SetFirstName()`.
- The type of the `Property` in the example is `string`.
- The name used with the `Object` is the `Property` name.

So we can use `FirstName` instead of directly calling `SetFirstName()` and `GetFirstName()`.

---

## 💻 Example: `FirstName`

```cpp
#include <iostream>
using namespace std;

class clsPerson
{
private:
string _FirstName;

public:

void SetFirstName(string FirstName) 
{
	_FirstName = FirstName;
}

string GetFirstName()
{
	return _FirstName;
}

__declspec(property(get = GetFirstName, put = SetFirstName)) string FirstName;

};

int main()
{

clsPerson Person1;

Person1.SetFirstName("Mohammed");
cout << Person1.GetFirstName() <<endl;

//instead of the above we only write this

Person1.FirstName = "Mohammed";
cout << Person1.FirstName;



return 0;

};
```

In the first part of `main()`, we use the previous method:

`Person1.SetFirstName("Mohammed");`

Then we get the value with:

`Person1.GetFirstName()`

After defining the `Property`, we can use the shorter form:

`Person1.FirstName = "Mohammed";`

Then:

`cout << Person1.FirstName;`

When we assign a value to `FirstName`, `SetFirstName()` is called through the mapping.

When we get the value of `FirstName`, `GetFirstName()` is called through the mapping.

---

## 📌 Property Name

The `Property` name is the name we use through the `Object`.

In the example, the name is `FirstName`.

The `Property` can have a different name, but a clear name that describes the data is better.

---

## 📌 Property Type

In the example, the type of `FirstName` is `string` because `GetFirstName()` returns a `string`.

If the `Property` works with another type, the suitable type is used for it.

---

## 📌 Set and Get

The `Set` and `Get` functions do not disappear when we use a `Property`.

They still exist inside the `Class`:

- `SetFirstName()` stores the value.
- `GetFirstName()` returns the value.

The `Property` makes access to them easier through one name.

---

## 📚 Terminology

| Term | Meaning |
|---|---|
| Property | A name used to access data through `Get` and `Set` |
| Property Mapping | Linking a `Property` to `Get` and `Set` functions |
| Get | A function that returns the value |
| Set | A function that stores or changes the value |
| `get` | Part of the `Property` definition that selects the get function |
| `put` | Part of the `Property` definition that selects the set function |
| `__declspec(property(...))` | Syntax used to define and link the `Property` in this example |
| Assignment | Giving a value using `=` |
| Object | An instance of a `Class` |
| Class | A type used to create objects |

---

## ⚠️ Notes

- Using a `Property` does not remove the `Set` and `Get` functions.
- `=` with the `Property` calls its linked `Set` function.
- Getting the value of the `Property` calls its linked `Get` function.
- In the example, `FirstName` is linked to `GetFirstName()` and `SetFirstName()`.
- The name used with the `Object` is the `Property` name, not the `private` member name.
- `_FirstName` stays `private` and is not accessed directly from outside the `Class`.
- The `__declspec(property(...))` line creates the mapping between the `Property` and the `Get` and `Set` functions in this example.

---

## 💡 Key Idea

Instead of writing:

`Person1.SetFirstName("Mohammed");`

and:

`Person1.GetFirstName();`

we can use:

`Person1.FirstName = "Mohammed";`

and:

`Person1.FirstName`

The `Property` maps assignment to the `Set` function and getting the value to the `Get` function.

---

## 🔑 Summary

- `Properties` can be used in an easier way through `=`.
- `get = GetFirstName` links the `Property` to `GetFirstName()`.
- `put = SetFirstName` links the `Property` to `SetFirstName()`.
- Assigning to `FirstName` uses `SetFirstName()`.
- Getting the value of `FirstName` uses `GetFirstName()`.
- The `Set` and `Get` functions still exist, and the `Property` gives an easier way to access them.
- `__declspec(property(...))` is the syntax used for the mapping in this example.
