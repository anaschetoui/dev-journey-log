# Static Functions

---

## 📝 مقدمة

بعد تعلّم `Static Data Members`، ننتقل إلى `Static Functions`.

مثل `Static Data Member`، تكون `Static Function` على مستوى الـ `Class` وليس على مستوى كل `Object`. لذلك يمكن استدعاؤها مباشرة من خلال اسم الـ `Class` دون الحاجة إلى إنشاء `Object`.

---

## 🧠 مراجعة سريعة

`Static Data Member` يكون مشتركًا بين جميع الـ `Objects` ويكون على مستوى الـ `Class`.

الفكرة نفسها تُستخدم مع `Static Function`: تكون الدالة مشتركة وعلى مستوى الـ `Class`، لذلك يمكن استدعاؤها دون الحاجة إلى `Object`، ويمكن استخدامها من أي مكان يسمح فيه مستوى الوصول بذلك.

---

## 🎯 تعريف: Static Function

> **Static Function**
>
> دالة تكون على مستوى الـ `Class` وليست مرتبطة بـ `Object` معيّن.
>
> يمكن استدعاؤها دون إنشاء `Object`، ويمكن استدعاؤها من أي مكان يسمح فيه مستوى الوصول بذلك، وليس فقط من خلال الـ `Object`.

---

## ⚙️ استدعاء Static Function من خلال الـ Class

يمكن استدعاء `Static Function` مباشرة بهذه الطريقة:

`()clsA::Function1`

في هذا الشكل، لا نحتاج إلى إنشاء `Object` من `clsA`.

في المثال، `()Function1` هي `static`، ولذلك يمكن استدعاؤها مباشرة من خلال:

`()clsA::Function1`

وتُرجع القيمة `10`.

---

## 💻 مثال: Static Function

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
#include <iostream>
using namespace std;

class clsA
{
public:

    static int Function1()
    {
        return 10;
    }

    int Function2()
    {
        return 20;
    }
};

int main()
{
    // The following line calls static function directly via class no throught the object
    // At class level you can call only static methods and static members
    cout << clsA::Function1() << endl;

    // static methods can also be called throught the object.
    clsA A1, A2;

    cout << A1.Function1() << endl;
    cout << A1.Function2() << endl;
    cout << A2.Function1() << endl;
}
```

</div>

في بداية `()main`، يتم استدعاء `()Function1` مباشرة من خلال الـ `Class`:

`()clsA::Function1`

لا يوجد `Object` في هذه اللحظة، ومع ذلك يمكن استدعاء الدالة لأنها `static`.

---

## 📌 Static Function و Object

يمكن أيضًا استدعاء `Static Function` من خلال `Object`.

في المثال:

`()A1.Function1`

تعمل بشكل صحيح لأن `()Function1` هي `static`.

وكذلك:

`()A2.Function1`

تعمل أيضًا لأن الدالة على مستوى الـ `Class` وليست نسخة خاصة بـ `A1` أو `A2`.

---

## 📌 الفرق عن Function عادية

`()Function2` في المثال ليست `static`.

لذلك لا يمكن استدعاؤها من خلال اسم الـ `Class` مباشرة.

يجب أن يكون لدينا `Object` لاستدعائها، مثل:

`()A1.Function2`

وتُرجع القيمة `20`.

إذن:

- `Static Function` → يمكن استدعاؤها دون `Object`، ومن أي مكان يسمح فيه مستوى الوصول بذلك.
- `Normal Function` → تحتاج إلى `Object` لاستدعائها.

---

## 📌 استدعاء الدالة من مستوى الـ Class

عند الاستدعاء باستخدام:

`()clsA::Function1`

نحن على مستوى الـ `Class`.

في هذا المستوى يمكن استدعاء الأعضاء `static`، ومنها `Static Functions`.

أما `()Function2`، فهي ليست `static`، لذلك تحتاج إلى `Object`.

---

## 📌 Static Function كدالة مشتركة

يمكن اعتبار `Static Function` دالة مشتركة على مستوى الـ `Class`.

لا تحتاج إلى `Object` حتى يتم استدعاؤها، ويمكن استدعاؤها من أي مكان يسمح فيه مستوى الوصول بذلك. كما لا توجد نسخة منفصلة منها لكل `Object`.

وهذا يجعلها مناسبة عندما تكون الدالة مرتبطة بالـ `Class` نفسها وليس بكائن معيّن.

---

## 📚 المصطلحات

| المصطلح | المعنى |
|---|---|
| Static Function | دالة تكون على مستوى الـ `Class` ويمكن استدعاؤها دون `Object` |
| `::` | رمز الوصول إلى عضو من خلال اسم الـ `Class` |
| Class Level | مستوى الـ `Class` |
| Static Method | اسم آخر لـ `Static Function` |
| Normal Function | دالة غير `static` تحتاج إلى `Object` لاستدعائها |

---

## ⚠️ ملاحظات

- `Static Function` تكون على مستوى الـ `Class`.
- يمكن استدعاؤها باستخدام `()ClassName::FunctionName`.
- لا تحتاج إلى `Object` لاستدعائها.
- يمكن أيضًا استدعاء `Static Function` من خلال `Object` كما يظهر في المثال.
- يمكن استدعاؤها من أي مكان يسمح فيه مستوى الوصول بذلك.
- `()Function2` غير `static`، لذلك تحتاج إلى `Object`.
- على مستوى الـ `Class` يتم استدعاء الأعضاء `static`.

---

## 💡 الفكرة الأساسية

`Static Function` هي دالة مشتركة على مستوى الـ `Class`.

لذلك يمكن استدعاؤها قبل إنشاء أي `Object`، ويمكن أيضًا استدعاؤها من أي مكان يسمح فيه مستوى الوصول بذلك، مثل:

`()clsA::Function1`

أما الدالة العادية مثل `()Function2` فتحتاج إلى `Object`.

---

## 🔑 ملخص

- `Static Function` تكون على مستوى الـ `Class`.
- يمكن استدعاؤها مباشرة باستخدام `::`.
- لا تحتاج إلى `Object` عند استدعائها من خلال الـ `Class`.
- يمكن أيضًا استدعاؤها من خلال `Object`.
- الدالة غير `static` تحتاج إلى `Object`.
- في المثال، `()Function1` هي `static` و`()Function2` ليست `static`.

## 📝 Introduction

After learning about `Static Data Members`, we move to `Static Functions`.

Like a `Static Data Member`, a `Static Function` is at the `Class` level instead of being tied to one `Object`. This means we can call it directly through the `Class` name without creating an `Object`.

---

## 🧠 Quick Recap

A `Static Data Member` is shared by all `Objects` and belongs to the `Class` level.

The same idea is used with a `Static Function`. It is shared and belongs to the `Class` level, so it can be called without an `Object` and from any place where its access is allowed.

---

## 🎯 Definition: Static Function

> **Static Function**
>
> A function that belongs to the `Class` level and is not tied to one `Object`.
>
> It can be called without creating an `Object`, and it can be called from any place where its access is allowed, not only through an `Object`.

---

## ⚙️ Calling a Static Function Through the Class

A `Static Function` can be called directly like this:

`clsA::Function1()`

We do not need to create an `Object` of `clsA`.

In the example, `Function1()` is `static`, so we can call it directly with:

`clsA::Function1()`

It returns `10`.

---

## 💻 Example: Static Function

```cpp
#include <iostream>
using namespace std;

class clsA
{
public:

    static int Function1()
    {
        return 10;
    }

    int Function2()
    {
        return 20;
    }
};

int main()
{
    // The following line calls static function directly via class no throught the object
    // At class level you can call only static methods and static members
    cout << clsA::Function1() << endl;

    // static methods can also be called throught the object.
    clsA A1, A2;

    cout << A1.Function1() << endl;
    cout << A1.Function2() << endl;
    cout << A2.Function1() << endl;
}
```

At the start of `main()`, `Function1()` is called directly through the `Class`:

`clsA::Function1()`

There is no `Object` at this point, but the function can still be called because it is `static`.

---

## 📌 Static Function and Object

A `Static Function` can also be called through an `Object`.

In the example:

`A1.Function1()`

works because `Function1()` is `static`.

Also:

`A2.Function1()`

works because the function belongs to the `Class` level, not to a specific `A1` or `A2`.

---

## 📌 Difference from a Normal Function

`Function2()` in the example is not `static`.

So we cannot call it directly through the `Class` name.

We need an `Object`, for example:

`A1.Function2()`

It returns `20`.

So:

- `Static Function` → can be called without an `Object`, from any place where access is allowed.
- `Normal Function` → needs an `Object`.

---

## 📌 Calling from the Class Level

When we call:

`clsA::Function1()`

we are working at the `Class` level.

At this level, we can call `static` members, including `Static Functions`.

`Function2()` is not `static`, so it needs an `Object`.

---

## 📌 Static Function as a Shared Function

A `Static Function` can be viewed as a shared function at the `Class` level.

It does not need an `Object` to be called, and it can be called from any place where its access is allowed. There is not a separate copy of the function for each `Object`.

This makes it useful when the function is related to the `Class` itself instead of one specific object.

---

## 📚 Terminology

| Term | Meaning |
|---|---|
| Static Function | A function at the `Class` level that can be called without an `Object` |
| `::` | The operator used to access a member through the `Class` name |
| Class Level | The level of the `Class` itself |
| Static Method | Another name for `Static Function` |
| Normal Function | A non-static function that needs an `Object` to be called |

---

## ⚠️ Notes

- A `Static Function` is at the `Class` level.
- It can be called using `ClassName::FunctionName()`.
- It does not need an `Object` when called this way.
- A `Static Function` can also be called through an `Object`, as shown in the example.
- It can be called from any place where its access is allowed.
- `Function2()` is not `static`, so it needs an `Object`.
- At the `Class` level, `static` members can be called.

---

## 💡 Key Idea

A `Static Function` is a shared function at the `Class` level.

So it can be called before any `Object` is created, and it can also be called from any place where its access is allowed, for example:

`clsA::Function1()`

A normal function such as `Function2()` needs an `Object`.

---

## 🔑 Summary

- A `Static Function` belongs to the `Class` level.
- It can be called directly using `::`.
- It does not need an `Object` when called through the `Class`.
- It can also be called through an `Object`.
- A non-static function needs an `Object`.
- In the example, `Function1()` is `static` and `Function2()` is not.
