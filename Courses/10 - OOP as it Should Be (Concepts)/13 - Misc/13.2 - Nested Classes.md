# Nested Classes

---

## 📝 مقدمة

يمكن تعريف `Class` داخل `Class` أخرى.

في الدرس السابق كانت بيانات العنوان داخل `Structure`، أما هنا فأصبحت `clsAddress` كلاس كاملة داخل `clsPerson`.

---

## 🧠 مراجعة سريعة

`Structure` هي `Data Type`، ولذلك يمكن تعريفها داخل `Class`.

وكذلك يمكن تعريف `Class` داخل `Class` أخرى، لأن الـ `Class` نفسها نوع من أنواع البيانات.

---

## 🎯 تعريف: Nested Class

> **Nested Class**
>
> كلاس يتم تعريفها داخل كلاس أخرى.

في المثال:

`clsPerson`

تحتوي على:

`clsAddress`

لذلك:

`clsPerson` هي الـ `Enclosing Class`.

و:

`clsAddress` هي الـ `Inner Class`.

---

## ⚙️ تعريف الـ Nested Class

داخل `clsPerson` تم تعريف `clsAddress`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsPerson
{
    class clsAddress
    {
    public:
        string AddressLine1;
        string AddressLine2;
        string City;
        string Country;

        void Print()
        {
            cout << "\nAddress:\n";
            cout << AddressLine1 << endl;
            cout << AddressLine2 << endl;
            cout << City << endl;
            cout << Country << endl;
        }
    };
};
```

</div>

هنا `clsAddress` موجودة داخل `clsPerson`.

---

## 📌 استخدام `clsAddress` كعضو

بعد تعريف `clsAddress`، تم تعريف عضو من هذا النوع داخل `clsPerson`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
clsAddress Address;
```

</div>

إذن `Address` هو كائن من النوع `clsAddress` داخل `clsPerson`.

---

## ⚙️ الوصول إلى أعضاء الـ Nested Class

بعد إنشاء `Person1` من `clsPerson`، يمكن الوصول إلى `Address` ثم إلى الأعضاء الموجودة داخله باستخدام `.`.

مثل:

`Person1.Address.AddressLine1`

و:

`Person1.Address.City`

كما يمكن استدعاء:

`()Person1.Address.Print`

---

## 💻 مثال: استدعاء `()Print`

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
()Person1.Address.Print;
```

</div>

هذا الاستدعاء يصل إلى `Address` داخل `Person1`، ثم يستدعي `()Print` الموجودة داخل `clsAddress`.

---

## 📌 تهيئة بيانات العنوان

داخل `clsPerson` تم وضع قيم لبيانات `Address`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
Address.AddressLine1 = "Building 10";
Address.AddressLine2 = "Queen Rania Street";
Address.City = "Amman";
Address.Country = "Jordan";
```

</div>

---

## 💻 مثال: الكود الكامل

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud
#include<iostream>
using namespace std;

class clsPerson {

    class clsAddress
    {
    public:
        string AddressLine1;
        string AddressLine2;
        string City;
        string Country;

        void Print()
        {
            cout << "\nAddress:\n";
            cout << AddressLine1 << endl;
            cout << AddressLine2 << endl;
            cout << City << endl;
            cout << Country << endl;
        }
    };

public:
    string FullName;
    clsAddress Address;

    clsPerson()
    {
        FullName = "Mohammed Abu-Hadhoud";
        Address.AddressLine1 = "Building 10";
        Address.AddressLine2 = "Queen Rania Street";
        Address.City = "Amman";
        Address.Country = "Jordan";
    }

};

int main()

{

    clsPerson Person1;

    Person1.Address.Print();

    system("pause>0");
    return 0;
}
```

</div>

---

## 📌 Nested Class مثل أي Class

بما أن `clsAddress` أصبحت `Class`، يمكن أن تحتوي على دوال ومتغيّرات، ويمكن أن يكون لها `Constructor` و`Properties`.

في الكود الحالي تم استخدام دوال ومتغيّرات فقط.

إضافة `Constructor` و`Properties` ذُكرت كتدريب إضافي، ولم يتم تنفيذها في الكود المقدم.

---

## 📌 العلاقة بين `Person` و`Address`

`clsPerson` هي الـ `Enclosing Class`، و`clsAddress` هي الـ `Inner Class`.

أما `Address` فهو العضو الذي تم تعريفه من نوع `clsAddress` داخل `clsPerson`.

لذلك يمكن الوصول إليه بهذا الشكل:

`Person1.Address`

---

## 📚 المصطلحات

| المصطلح | المعنى |
|---|---|
| Nested Class | كلاس داخل كلاس أخرى |
| Inner Class | الكلاس الموجودة داخل كلاس أخرى |
| Enclosing Class | الكلاس التي تحتوي على كلاس أخرى |
| `clsPerson` | الـ `Enclosing Class` في المثال |
| `clsAddress` | الـ `Inner Class` في المثال |
| `Address` | عضو من النوع `clsAddress` |

---

## ⚠️ ملاحظات

- يمكن تعريف `Class` داخل `Class` أخرى.
- `clsPerson` هي الـ `Enclosing Class`.
- `clsAddress` هي الـ `Inner Class`.
- `Address` عضو من النوع `clsAddress`.
- يمكن الوصول إلى الحقول باستخدام `.`.
- المثال يستخدم `Person1.Address.Print()`.
- يمكن أن تحتوي الـ `Nested Class` على دوال ومتغيّرات، ويمكن أن يضاف إليها `Constructor` و`Properties`.

---

## 💡 الفكرة الأساسية

إذا كانت لدينا:

`clsPerson`

وبداخلها:

`clsAddress`

فإن `clsAddress` هي `Nested Class`.

ثم يتم تعريف `Address` داخل `clsPerson` من النوع `clsAddress`.

وبذلك يمكن الوصول إلى بيانات العنوان ودواله من خلال `Address`.

---

## 🔑 ملخص

- `Nested Class` هي `Class` داخل `Class` أخرى.
- `clsPerson` هي الـ `Enclosing Class`.
- `clsAddress` هي الـ `Inner Class`.
- `Address` عضو من النوع `clsAddress`.
- يمكن الوصول إلى بيانات العنوان مثل `Person1.Address.City`.
- يمكن استدعاء `Person1.Address.Print()`.
- يمكن للـ `Nested Class` أن تحتوي على دوال ومتغيّرات، ويمكن أن يكون لها `Constructor` و`Properties`.

## 📝 Introduction

A `Class` can be defined inside another `Class`.

In the previous lesson, the address data was inside a `Structure`. Here, it becomes `clsAddress`, a full class inside `clsPerson`.

---

## 🧠 Quick Recap

A `Structure` is a `Data Type`, so it can be defined inside a `Class`.

The same idea can be used with a `Class`, because a `Class` is also a data type.

---

## 🎯 Definition: Nested Class

> **Nested Class**
>
> A class defined inside another class.

In the example, `clsPerson` contains `clsAddress`.

So `clsPerson` is the `Enclosing Class`, and `clsAddress` is the `Inner Class`.

---

## ⚙️ Defining the Nested Class

Inside `clsPerson`, we define `clsAddress`:

```cpp
class clsPerson
{
    class clsAddress
    {
    public:
        string AddressLine1;
        string AddressLine2;
        string City;
        string Country;

        void Print()
        {
            cout << "\nAddress:\n";
            cout << AddressLine1 << endl;
            cout << AddressLine2 << endl;
            cout << City << endl;
            cout << Country << endl;
        }
    };
};
```

Here, `clsAddress` is inside `clsPerson`.

---

## 📌 Using `clsAddress` as a Member

After defining `clsAddress`, we define a member of this type inside `clsPerson`:

```cpp
clsAddress Address;
```

So `Address` is an object of type `clsAddress` inside `clsPerson`.

---

## ⚙️ Accessing Nested Class Members

After creating `Person1` from `clsPerson`, we can access `Address` and then its members using `.`.

For example:

`Person1.Address.AddressLine1`

and:

`Person1.Address.City`

We can also call:

`Person1.Address.Print()`

---

## 💻 Example: Calling `Print()`

```cpp
Person1.Address.Print();
```

This accesses `Address` inside `Person1`, then calls `Print()` inside `clsAddress`.

---

## 📌 Initializing Address Data

Inside `clsPerson`, values are assigned to `Address`:

```cpp
Address.AddressLine1 = "Building 10";
Address.AddressLine2 = "Queen Rania Street";
Address.City = "Amman";
Address.Country = "Jordan";
```

---

## 💻 Example: Complete Code

```cpp
//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud
#include<iostream>
using namespace std;

class clsPerson {

    class clsAddress
    {
    public:
        string AddressLine1;
        string AddressLine2;
        string City;
        string Country;

        void Print()
        {
            cout << "\nAddress:\n";
            cout << AddressLine1 << endl;
            cout << AddressLine2 << endl;
            cout << City << endl;
            cout << Country << endl;
        }
    };

public:
    string FullName;
    clsAddress Address;

    clsPerson()
    {
        FullName = "Mohammed Abu-Hadhoud";
        Address.AddressLine1 = "Building 10";
        Address.AddressLine2 = "Queen Rania Street";
        Address.City = "Amman";
        Address.Country = "Jordan";
    }

};

int main()

{

    clsPerson Person1;

    Person1.Address.Print();

    system("pause>0");
    return 0;
}
```

---

## 📌 A Nested Class Can Work Like a Class

Because `clsAddress` is a `Class`, it can contain functions and variables, and it can have a `Constructor` and `Properties`.

The current code uses functions and variables only.

Adding a `Constructor` and `Properties` was mentioned as extra practice, but they are not implemented in the provided code.

---

## 📌 Relation Between `Person` and `Address`

`clsPerson` is the `Enclosing Class`, and `clsAddress` is the `Inner Class`.

`Address` is the member defined inside `clsPerson` with type `clsAddress`.

So we can access it through:

`Person1.Address`

---

## 📚 Terminology

| Term | Meaning |
|---|---|
| Nested Class | A class inside another class |
| Inner Class | The class inside another class |
| Enclosing Class | The class that contains another class |
| `clsPerson` | The `Enclosing Class` in the example |
| `clsAddress` | The `Inner Class` in the example |
| `Address` | A member of type `clsAddress` |

---

## ⚠️ Notes

- A `Class` can be defined inside another `Class`.
- `clsPerson` is the `Enclosing Class`.
- `clsAddress` is the `Inner Class`.
- `Address` is a member of type `clsAddress`.
- We can access the fields using `.`.
- The example uses `Person1.Address.Print()`.
- A `Nested Class` can contain functions and variables, and it can have a `Constructor` and `Properties`.

---

## 💡 Key Idea

If we have:

`clsPerson`

and inside it:

`clsAddress`

then `clsAddress` is a `Nested Class`.

Then `Address` is defined inside `clsPerson` with type `clsAddress`.

This lets us access the address data and functions through `Address`.

---

## 🔑 Summary

- A `Nested Class` is a `Class` inside another `Class`.
- `clsPerson` is the `Enclosing Class`.
- `clsAddress` is the `Inner Class`.
- `Address` is a member of type `clsAddress`.
- We can access address data with `Person1.Address.City`.
- We can call `Person1.Address.Print()`.
- A `Nested Class` can contain functions and variables, and it can have a `Constructor` and `Properties`.
