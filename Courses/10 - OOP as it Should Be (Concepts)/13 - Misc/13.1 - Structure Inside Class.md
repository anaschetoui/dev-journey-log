# Structure Inside a Class

---

## 📝 مقدمة

يمكن تعريف `Structure` داخل `Class`.

كما يمكن للكلاس أن تحتوي على متغيّرات من أنواع مختلفة، يمكنها أيضًا أن تحتوي على `Structure` وتستخدمها لتعريف بيانات مرتبطة ببعضها.

---

## 🎯 تعريف: Structure داخل Class

> **Structure داخل Class**
>
> تعريف `Structure` داخل `Class` واستخدامها كنوع بيانات داخل الكلاس.

في المثال توجد `Structure` باسم:

`stAddress`

وتحتوي على بيانات العنوان.

---

## 💻 مثال: تعريف `stAddress`

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
class clsPerson
{
    struct stAddress
    {
        string AddressLine1;
        string AddressLine2;
        string City;
        string Country;
    };
};
```

</div>

تحتوي `stAddress` على:

`AddressLine1`

`AddressLine2`

`City`

`Country`

---

## 📌 استخدام Structure كعضو داخل Class

يمكن استخدام `stAddress` لتعريف عضو داخل `clsPerson`:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
stAddress Address;
```

</div>

هنا `Address` متغيّر من النوع `stAddress`.

---

## ⚙️ الوصول إلى بيانات Structure

بعد إنشاء `Person1` من `clsPerson`، يمكن الوصول إلى `Address` ثم إلى الحقول الموجودة داخله باستخدام النقطة `.`.

مثل:

`Person1.Address.AddressLine1`

و:

`Person1.Address.City`

---

## 💻 مثال: استخدام `Address`

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
Person1.Address.AddressLine1
Person1.Address.AddressLine2
Person1.Address.City
Person1.Address.Country
```

</div>

الترتيب هو:
<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

`Person1` → `Address` → الحقل المطلوب.

</div>

---

## 📌 تهيئة بيانات Structure

في `clsPerson` يتم وضع قيم لبيانات العنوان:

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
Address.AddressLine1 = "Building 10";
Address.AddressLine2 = "Queen Rania Street";
Address.City = "Amman";
Address.Country = "Jordan";
```

</div>

---

## 💻 مثال: الكود الكامل

<div dir="ltr" style="text-align:left;font-family:'Arial',sans-serif;">

```cpp
//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud

#include<iostream>

using namespace std;

class clsPerson
{
    struct stAddress
    {
        string AddressLine1;
        string AddressLine2;
        string City;
        string Country;
    };

public:
    string FullName;
    stAddress Address;

    clsPerson()
    {
        FullName = "Mohammed Abu-Hadhoud";

        Address.AddressLine1 = "Building 10";
        Address.AddressLine2 = "Queen Rania Street";
        Address.City = "Amman";
        Address.Country = "Jordan";
    }

    void PrintAddress()
    {
        cout << "
Address:
";
        cout << Address.AddressLine1 << endl;
        cout << Address.AddressLine2 << endl;
        cout << Address.City << endl;
        cout << Address.Country << endl;
    }
};

int main()
{
    clsPerson Person1;

    Person1.PrintAddress();

    system("pause>0");
    return 0;
}
```

</div>

## 📝 Introduction

A `Structure` can be defined inside a `Class`.

A class can contain variables of different types. It can also contain a `Structure` for related data.

---

## 🎯 Definition: Structure Inside a Class

> **Structure Inside a Class**
>
> Defining a `Structure` inside a `Class` and using it as a data type inside the class.

The example has a `Structure` named:

`stAddress`

It contains address data.

---

## 💻 Example: Defining `stAddress`

```cpp
class clsPerson
{
    struct stAddress
    {
        string AddressLine1;
        string AddressLine2;
        string City;
        string Country;
    };
};
```

The `Structure` contains:

`AddressLine1`

`AddressLine2`

`City`

`Country`

---

## 📌 Using a Structure as a Class Member

We can use `stAddress` to define a member inside `clsPerson`:

```cpp
stAddress Address;
```

Here, `Address` is a variable of type `stAddress`.

---

## ⚙️ Accessing Structure Data

After creating `Person1` from `clsPerson`, we can access `Address` and then its fields using the dot `.`.

For example:

`Person1.Address.AddressLine1`

and:

`Person1.Address.City`

---

## 💻 Example: Using `Address`

```cpp
Person1.Address.AddressLine1
Person1.Address.AddressLine2
Person1.Address.City
Person1.Address.Country
```

The order is:

`Person1` → `Address` → the required field.

---

## 📌 Initializing Structure Data

Inside `clsPerson`, values are assigned to the address data:

```cpp
Address.AddressLine1 = "Building 10";
Address.AddressLine2 = "Queen Rania Street";
Address.City = "Amman";
Address.Country = "Jordan";
```

---

## 💻 Example: Complete Code

```cpp
//ProgrammingAdivces.com
//Mohammed Abu-Hadhoud

#include<iostream>

using namespace std;

class clsPerson
{
    struct stAddress
    {
        string AddressLine1;
        string AddressLine2;
        string City;
        string Country;
    };

public:
    string FullName;
    stAddress Address;

    clsPerson()
    {
        FullName = "Mohammed Abu-Hadhoud";

        Address.AddressLine1 = "Building 10";
        Address.AddressLine2 = "Queen Rania Street";
        Address.City = "Amman";
        Address.Country = "Jordan";
    }

    void PrintAddress()
    {
        cout << "
Address:
";
        cout << Address.AddressLine1 << endl;
        cout << Address.AddressLine2 << endl;
        cout << Address.City << endl;
        cout << Address.Country << endl;
    }
};

int main()
{
    clsPerson Person1;

    Person1.PrintAddress();

    system("pause>0");
    return 0;
}
```

---

## 📌 Printing Address Data

The function:

`PrintAddress()`

uses the four fields inside `Address` and prints them.

---

## ⚙️ A Structure Is a Data Type

A `Structure` can be used as a data type like other types.

In the example, `Address` is a variable of type `stAddress`.

---

## 📚 Terminology

| Term | Meaning |
|---|---|
| Structure | A data type that contains a group of variables |
| `stAddress` | The `Structure` name in the example |
| `Address` | A variable of type `stAddress` |
| Field | A variable inside the `Structure` |

---

## ⚠️ Notes

- A `Structure` can be defined inside a `Class`.
- `stAddress` contains the address data.
- `Address` is a variable of type `stAddress`.
- We can access the fields using `.`.
- Example: `Person1.Address.City`

---

## 💡 Key Idea

A `Structure` can group related data into one type.

In the example:

`stAddress`

contains:

`AddressLine1`

`AddressLine2`

`City`

`Country`

Then `Address` is defined as a member inside `clsPerson`.

---

## 🔑 Summary

- A `Structure` can be defined inside a `Class`.
- `stAddress` is the `Structure` used in the example.
- It contains four address fields.
- `Address` is a variable of type `stAddress`.
- We access the fields using `.`.
